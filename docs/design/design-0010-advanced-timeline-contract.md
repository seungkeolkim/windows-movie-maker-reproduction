# DESIGN-0010: 고급 타임라인과 세션 행동 계약

## 상태

승인 및 W-08 구현 완료. 이 문서는 W-04의 단일 클립 명령 위에 추가된 선택, 그룹 편집,
스토리보드와 확대 상태의 경계를 고정한다.

## 상태 소유권

`Project`에는 미디어 참조와 네 고정 트랙의 지속 클립 값만 들어간다. 선택 ID, 대표 선택,
타임라인·스토리보드 모드, 50~200%의 25% 단위 확대, 스크롤과 재생 위치는 세션 상태다.
세션 상태 변경은 프로젝트 JSON, dirty 비교와 명령 이력에 들어가지 않는다.

`TimelineSelection`은 선택 ID를 현재 트랙 순서로 정규화하고 대표 ID를 하나 유지한다. 단일
선택은 기존 속성·미리 보기 문맥을 사용한다. 다중 선택은 같은 고정 트랙만 허용하며 컨트롤러가
전체 선택을 검증한 뒤 한 번에 교체한다. 편집 후 사라진 ID는 제거하고 대표 ID가 사라지면 남은
첫 ID를 선택한다. 남은 ID가 없으면 선택을 비운다.

Qt의 확장 선택이 같은 목록 안에서 `Ctrl` 개별 토글과 `Shift` 연속 범위를 만든다. 컨트롤러는
다른 트랙이나 존재하지 않는 ID가 섞인 입력을 일부 적용하지 않고 기존 선택을 유지한다.

## 지속 편집 명령

W-08 명령은 기존 `CommandExecutor`를 사용하며 성공한 사용자 행동 하나가 이력 하나다.

- `DuplicateTimelineClip`은 호출자가 제공한 새 ID를 검증하고 원본 참조, source 구간, 재생
  속도와 오디오 값을 보존한 복제본을 원본 바로 뒤에 삽입한다.
- `MoveVisualClipGroup`은 선택을 기존 트랙 순서로 모은 뒤 나머지 클립 사이의 단일 삽입점으로
  옮긴다. 결과 시각 트랙은 0부터 다시 연속 배치한다.
- `MoveAbsoluteClipGroup`은 음악·내레이션·텍스트 한 트랙의 모든 선택에 동일한 정수 시간
  델타를 적용한다. 상대 간격을 보존하며 하나라도 0보다 앞서면 전체를 거부한다.
- `DeleteClipGroup`은 빈 선택, 중복 ID, 누락 ID와 혼합 트랙을 모두 검증한 뒤 삭제한다.

오류는 `TimelineEditRejected`와 `TimelineEditErrorCode`로 빈 선택, 누락 ID, 혼합 트랙,
비호환 선택, 범위 밖, ID 충돌, 무변경과 오래된 상태를 구분한다. 실패와 원위치 놓기는
프로젝트 객체 및 이력 위치를 바꾸지 않는다.

역명령은 전체 프로젝트 스냅샷을 저장하지 않는다. 복제는 새 ID 삭제, 삭제는 제거한 클립과
원래 인덱스, 시각 이동은 이전·이후 ID 순서, 절대 시간 이동은 반대 델타와 예상 클립 값만
보관한다. 시각 트랙 편집은 보조 트랙의 절대 시작 시간을 변경하지 않는다. 인접 관계를 쓰는
후속 기능은 명령 적용 뒤 명시적인 정리 경계를 거쳐야 한다.

## 보기와 입력

타임라인과 스토리보드는 같은 컨트롤러의 `Project`와 선택을 투영한다. 타임라인은 눈금,
재생 헤드와 네 고정 트랙을 표시한다. 스토리보드는 시각 트랙을 큰 순서 카드로 표시하고 음악,
내레이션과 텍스트 수를 요약한다. 보기 전환은 선택과 재생 위치를 유지한다.

확대 버튼, 슬라이더와 `Ctrl+휠`은 같은 50~200% 경계를 사용한다. 확대는 클립 표시 폭만
바꾸며 포인터 주변 스크롤 비율을 가능한 범위에서 복원한다. 내부 끌기는 표시 목록을 선반영하지
않고 유효한 놓기에서 시각 그룹 이동 명령 하나만 실행한다. 취소, 외부 놓기, 무효 위치와
원위치 놓기는 이력을 만들지 않는다.

`Ctrl+D`, `Delete`, `Ctrl+Z`, `Ctrl+Y`는 `QLineEdit` 또는 `QTextEdit` 포커스에서 프로젝트
편집을 실행하지 않는다. `Alt+Left`, `Alt+Right`는 시각 선택을 한 삽입 단계, 보조 트랙 선택을
1초 공통 델타로 이동한다. `Ctrl+Shift+V`는 두 보기를 전환한다. 목록의 표준 키보드 선택과
메뉴·도구 모음의 undo/redo도 같은 컨트롤러 경계를 사용한다.

## 출력 중 편집

W-07 출력은 시작 시 불변 프로젝트 스냅샷을 잡는다. 따라서 출력 중에도 W-08 편집을 허용하며
진행 중 출력은 시작 스냅샷을 계속 사용한다. 새 편집 결과는 다음 출력에서만 반영된다.

## 검증

집중 테스트는 복제 속성 보존, 그룹 이동·삭제 원자성, undo/redo와 이력 분기, 혼합 선택 거부,
선택 정리, 보기·확대의 무변경 및 텍스트 포커스를 확인한다. Hypothesis 테스트는 임의의 시각
클립 길이와 그룹에 대해 고유 ID, 0부터의 연속 배치와 undo/redo 왕복을 확인한다.

## 범위 밖

무제한 레이어, 마커, 슬립 편집, 속도 램핑, 영구 행동 이력, W-09 효과와 W-10 자동 저장·프록시는
이 계약에 포함하지 않는다.
