- 작성일: 2026-09-06
- 기능 기준:
  [PRODUCT-0002: 제품 기능 인벤토리](../product/product-0002-feature-inventory.md)
- 경험 기준:

## 목적

이 문서는 MVP와 1.0 기능을 제공할 화면, 주요 화면 영역, 대화상자와 배치 관계를 정의한다.
개별 버튼의 조건과 상태 변화는 [DESIGN-0002](design-0002-element-functions.md)에서 다룬다.

화면 구조는 처음 사용하는 사람이 `가져오기 → 배치 → 편집 → 미리 보기 → 저장 → 출력`
흐름을 한 창 안에서 이해할 수 있게 하는 것을 우선한다. 자주 쓰는 MVP 기능은 항상 보이는
영역에 두고, 1.0의 세부 설정은 메뉴와 선택 기반 속성 패널에 점진적으로 노출한다.

## 화면 설계 원칙

- 주 편집 작업은 `S-EDITOR` 하나에서 끝낼 수 있게 한다.
- 미디어 보관함, 미리 보기와 타임라인은 서로의 맥락을 잃지 않도록 동시에 표시한다.
- 속성 패널은 현재 선택한 대상에 맞는 항목만 보여 준다.
- 새 창은 장시간 독립 작업이나 실행 환경 준비에만 사용한다.
- 짧은 선택과 확인은 대화상자 또는 팝오버로 제공한다.
- 오류와 빈 상태는 별도 페이지로 숨기지 않고 문제가 발생한 영역 안에서 설명한다.
- 메뉴는 전체 기능의 안정적인 탐색 경로이고, 도구 모음은 자주 쓰는 기능의 빠른 경로다.
- 색상만으로 선택, 오류, 비활성화와 진행 상태를 표현하지 않는다.

화면 전반의 키보드 탐색, 고대비·배율, 단축키와 언어 확장 규칙은 각각
`F-EXPERIENCE-03`~`05`, `F-EXPERIENCE-07`에 연결한다. 1.0의 검증 기준 언어는 한국어이며,
다른 언어를 지원하게 되면 같은 레이아웃 크기와 오류·행동 용어의 일관성을 언어별로 다시
검증한다.

## 화면 식별자와 유형

| 식별자 | 유형 | 이름 | 역할 |
| --- | --- | --- | --- |
| `S-EDITOR` | 메인 윈도우 | 편집기 | 프로젝트의 가져오기, 편집, 미리 보기, 저장과 출력의 중심 |
| `S-START` | 메인 윈도우 상태 | 시작 화면 | 새 프로젝트, 프로젝트 열기와 최근 프로젝트 진입 |
| `S-LIBRARY` | 고정/접이식 패널 | 미디어 보관함 | 가져온 미디어 탐색, 선택, 추가와 제거 |
| `S-PREVIEW` | 중앙 프레임 | 미리 보기 | 현재 편집 결과와 재생 위치 표시 및 탐색 |
| `S-INSPECTOR` | 고정/접이식 패널 | 속성 | 선택한 미디어, 클립, 오디오, 텍스트, 전환 또는 프로젝트 설정 |
| `S-TIMELINE` | 중앙 프레임 | 스토리보드·타임라인 | 장면, 음악, 내레이션과 텍스트의 시간 배치 및 편집 |
| `S-EXPORT-SETTINGS` | 모달 대화상자 | 동영상 저장 | 파일 위치, 원본 유지 또는 해상도·품질 설정 |
| `S-TASK-PROGRESS` | 비모달 작업 패널 | 작업 진행 | 출력, 프록시, 파형 등 긴 작업의 진행·취소·결과 |
| `S-MISSING-MEDIA` | 모달 대화상자 | 누락 미디어 | 누락 항목과 영향을 확인하고 1.0에서 다시 연결 |
| `S-RECOVERY` | 모달 대화상자 | 프로젝트 복구 | 자동 저장본과 정상 저장본을 비교하여 복원 여부 선택 |
| `S-NARRATION` | 비모달 대화상자 | 내레이션 녹음 | 입력 장치, 녹음 상태와 프로젝트 추가 결과 표시 |
| `S-ONBOARDING` | 단계형 모달 | 시작 안내 | 첫 실행 기본 흐름과 예제 프로젝트 진입 |
| `S-RUNTIME` | 별도 윈도우 | 실행 준비 및 진단 | Windows 런처의 환경 준비, 복구, 실행과 진단 로그 |
| `S-MESSAGE` | 공통 대화상자/알림 | 확인 및 오류 | 저장하지 않은 변경, 실패 이유와 다음 행동 표시 |
| `S-SYSTEM-FILE` | 운영체제 대화상자 | 파일 선택 | 미디어 가져오기, 프로젝트 열기·저장과 출력 위치 선택 |

## S-EDITOR: 메인 편집 윈도우

### 기본 레이아웃

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 제목 표시줄: 프로젝트 이름 · 저장 상태                         창 제어      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 메뉴: 파일  편집  클립  오디오  텍스트  효과  보기  도움말                 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 명령: 새로 만들기  열기  저장 │ 가져오기  제거 │ 실행취소/다시실행 │ 출력  │
├──────────────────┬──────────────────────────────┬────────────────────────────┤
│ S-LIBRARY        │ S-PREVIEW                    │ S-INSPECTOR                │
│ 미디어 보관함    │                              │ 선택 대상의 속성           │
│                  │       영상 미리 보기         │                            │
│ 필터/항목 그리드 │                              │ 클립/오디오/텍스트/전환    │
│                  │ 재생 · 시간 · 탐색           │ 프로젝트 설정              │
├──────────────────┴──────────────────────────────┴────────────────────────────┤
│ S-TIMELINE: 스토리보드/타임라인 · 시간 눈금 · 재생 헤드 · 확대/축소        │
│ 영상/사진  [클립 1────────][클립 2────][사진────]                           │
│ 음악            [──────── 배경 음악 ───────────────]                        │
│ 내레이션                 [음성──────]                                        │
│ 텍스트                    [캡션────]                                         │
├──────────────────────────────────────────────────────────────────────────────┤
│ 상태 표시줄: 현재 도움말 · 프로젝트 길이 · 백그라운드 작업 · 오류 상태     │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 크기와 분할

- 기본 창 크기는 1440×900 논리 픽셀로 한다.
- 최소 창 크기는 1024×640 논리 픽셀로 하고 1280×720에서 모든 MVP 흐름을 검증한다.
- 왼쪽 보관함은 기본 260픽셀, 최소 220픽셀이다.
- 오른쪽 속성 패널은 기본 300픽셀, 최소 260픽셀이다.
- 중앙 미리 보기 영역은 나머지 폭을 사용하며 최소 420픽셀을 우선 확보한다.
- 타임라인은 기본적으로 작업 영역 높이의 약 40%를 사용하고 최소 280픽셀을 확보한다.
- 사용자는 보관함·속성·미리 보기와 타임라인 사이의 분할선을 조절할 수 있다.
- 폭이 부족하면 속성 패널을 먼저 접고 `속성` 명령으로 다시 연다. 보관함과 타임라인은 MVP
  편집 중 기본적으로 유지한다.
- 패널을 접어도 선택, 재생과 편집 상태는 유지한다.

### 포커스 이동 순서

기본 `Tab` 순서는 메뉴 및 도구 모음, 보관함, 미리 보기 조작, 속성, 타임라인, 상태 표시줄의
대화 가능한 항목 순이다. 패널 안에서는 시각적 위에서 아래, 왼쪽에서 오른쪽 순서와
일치시킨다. 접힌 패널과 비활성화된 항목은 포커스 순서에서 제외한다.

### 제목 및 저장 상태

제목 표시줄은 저장된 프로젝트명을 보여 준다. 새 프로젝트는 `제목 없음`으로 표시하고
저장하지 않은 변경이 있으면 이름 뒤에 `*`를 붙인다. 현재 프로젝트와 관계없는 마케팅 문구나
코덱 이름은 제목 표시줄에 넣지 않는다.

### 항상 보이는 명령

도구 모음에는 MVP에서 가장 자주 사용하는 다음 명령만 기본 노출한다.

- 새 프로젝트
- 프로젝트 열기
- 저장
- 미디어 가져오기
- 보관함에서 제거
- 실행 취소와 다시 실행 위치 예약
- 클립 분할
- 선택 항목 삭제
- 동영상 저장

실행 취소·다시 실행 버튼은 전체 레이아웃을 재작업하지 않도록 MVP 목업부터 자리를
확보한다. 실제 사용자 기능은 1.0에서 활성화한다. MVP 구현 내부에는 ADR-0002의 명령 및
행동 이력 기반을 둔다.

## S-START: 시작 상태

타임라인에 미디어가 없고 사용자가 편집을 시작하지 않았을 때 중앙 작업 영역에 표시한다.

- 주 행동: `미디어 가져오기`
- 보조 행동: `새 프로젝트`, `프로젝트 열기`
- 1.0 보조 영역: 최근 프로젝트, 예제 프로젝트, 시작 안내
- 최근 프로젝트가 없어도 빈 목록을 큰 오류처럼 표시하지 않는다.
- 사용자가 미디어를 가져오거나 프로젝트를 열면 같은 `S-EDITOR` 안의 편집 상태로 전환한다.

연결 기능: `F-PROJECT-01`, `04`, `06`, `F-MEDIA-01`, `F-EXPERIENCE-06`.

## S-LIBRARY: 미디어 보관함

### 구성

- 헤더: `미디어` 제목, 가져오기 버튼, 패널 메뉴
- 필터: 전체, 영상, 사진, 오디오
- 항목 영역: 썸네일 또는 종류 아이콘, 파일명, 길이, 상태 배지
- 빈 상태: 파일 선택 가져오기와 1.0 드래그 앤 드롭 안내
- 오류 상태: 실패한 항목의 이유와 다시 선택 행동
- 하단 요약: 항목 수, 분석 또는 백그라운드 작업 상태

### 배치 규칙

- 기본은 썸네일 그리드이며 좁은 폭에서는 한 열 목록으로 자연스럽게 바뀐다.
- 선택 항목은 테두리, 배경과 접근성 상태를 함께 사용한다.
- 영상, 사진, 오디오는 아이콘과 텍스트를 함께 사용해 구분한다.
- 누락되거나 읽을 수 없는 항목도 위치를 유지하고 경고 배지를 표시한다.
- 항목을 타임라인에 추가하는 주 경로는 더블클릭과 끌어 놓기이며, 키보드 사용자는 메뉴 또는
  `타임라인에 추가` 명령을 사용한다.

연결 기능: `F-MEDIA-01`~`09`, `F-TIMELINE-01`, `F-AUDIO-03`, `F-AUDIO-07`.

## S-PREVIEW: 미리 보기

### 구성

- 미리 보기 캔버스
- 현재 장면 또는 빈 상태 설명
- 재생/일시 정지 버튼
- 이전·다음 프레임 버튼 자리
- 현재 시간과 전체 길이
- 탐색 슬라이더
- 음소거 상태 표시

### 배치 규칙

- 캔버스는 사용 가능한 중앙 공간에서 가장 큰 직사각형을 사용한다.
- 프로젝트 화면 비율을 유지하고 남는 공간은 중립적인 어두운 배경으로 표시한다.
- 영상이 없으면 `타임라인에 미디어를 추가하세요`와 연결 행동을 표시한다.
- 재생 조작은 캔버스 바로 아래 한 줄에 두고 타임라인 재생 헤드와 항상 같은 위치를 표시한다.
- 프레임 이동은 1.0 기능이지만 레이아웃 검증을 위해 목업에서 확인할 수 있다.

연결 기능: `F-PREVIEW-01`~`05`, `F-EXPERIENCE-01`, `04`.

## S-INSPECTOR: 선택 기반 속성

속성 패널은 동시에 하나의 문맥만 보여 준다. 선택 대상이 바뀌면 같은 패널 안에서 페이지가
전환되며 새 대화상자를 열지 않는다.

| 선택 문맥 | 표시 내용 | 연결 기능 |
| --- | --- | --- |
| 선택 없음 | 프로젝트 이름, 화면과 출력 요약 | `F-VISUAL-04`, `F-EXPORT-01` |
| 미디어 항목 | 파일명, 종류, 길이, 해상도, 경로와 상태 | `F-MEDIA-02`, `03`, `06`, `07` |
| 영상 클립 | 시작·끝, 길이, 속도, 원본음, 회전, 맞춤·채움, 효과 | `F-TIMELINE-05`, `07`, `F-AUDIO-01`, `02`, `F-VISUAL-01`~`03`, `07`, `08` |
| 사진 클립 | 표시 시간, 회전, 맞춤·채움, 효과 | `F-TIMELINE-06`, `F-VISUAL-01`~`03`, `07`, `08` |
| 음악 클립 | 시작, 사용 구간, 음량, 음소거, 페이드 | `F-AUDIO-03`~`06` |
| 내레이션 클립 | 시작, 사용 구간, 음량, 음소거, 페이드 | `F-AUDIO-06`~`09` |
| 텍스트 | 종류, 내용, 서식, 위치, 시작과 길이, 애니메이션 | `F-TEXT-01`~`06` |
| 전환 | 종류와 길이 | `F-VISUAL-05`, `06` |

속성의 숫자값은 단위와 유효 범위를 함께 표시한다. 적용 즉시 미리 보기와 타임라인에
반영하되 텍스트 입력처럼 중간 상태가 필요한 항목은 명확한 적용 시점을 둔다.

## S-TIMELINE: 스토리보드와 타임라인

### 공통 헤더

- 스토리보드/타임라인 보기 전환
- 현재 시간과 전체 길이
- 축소, 확대와 맞춤 보기
- 선택 항목에 적용되는 분할 및 삭제 빠른 명령

### 트랙 순서

1. 영상·사진 스토리 라인
2. 원본 오디오 표시 영역
3. 배경 음악 트랙
4. 내레이션 트랙
5. 텍스트 레이어

원본 오디오는 영상 클립에 소속되며 독립적인 무제한 트랙으로 분리하지 않는다. 음악,
내레이션과 텍스트는 각 용도가 고정된 트랙을 사용한다.

### 클립 표현

- 영상·사진: 썸네일, 이름, 사용 길이와 누락 상태
- 음악·내레이션: 이름, 길이, 음량 상태와 1.0 파형
- 텍스트: 제목/캡션/크레딧 종류, 내용 일부와 표시 구간
- 전환: 인접한 영상·사진 클립 경계의 작은 전환 표식
- 선택: 테두리와 배경, 키보드 포커스를 별도로 표현
- 트리밍: 클립 양 끝의 조절 손잡이
- 재생 헤드: 모든 트랙을 가로지르는 선과 시간 표시

### 보기별 역할

- MVP 기본 타임라인은 시간 길이와 오디오 배치를 함께 보여 준다.
- 1.0 스토리보드는 장면 순서와 전환을 큰 카드로 단순하게 보여 준다.
- 두 보기는 같은 프로젝트 상태와 선택을 공유한다.
- 확대·축소는 화면상의 픽셀 폭만 바꾸고 편집 시간을 변경하지 않는다.

연결 기능: `F-TIMELINE-01`~`14`, `F-AUDIO-03`~`10`, `F-TEXT-01`~`06`,
`F-VISUAL-05`, `06`.

## S-EXPORT-SETTINGS: 동영상 저장

### 구성

- 출력 파일명과 위치
- 출력 크기: `원본 비율·해상도 유지`, `720p`, `1080p`
- 원본 유지 기준과 예상 결과 크기 설명
- 1.0 프레임률과 품질 프리셋
- 예상 화면 비율, 해상도, 길이와 파일 크기 요약
- `저장 시작`과 `취소`

하나의 동영상 파일은 고정된 화면 비율과 해상도를 사용한다. 서로 다른 원본이 섞인 경우
`원본 유지`가 어떤 기준 미디어를 사용하는지와 다른 미디어의 여백 처리 결과를 설정 요약과
미리 보기에서 설명한다. 세부 기준은 DESIGN-0002와 MOCK-0001에서 확정한다.

연결 기능: `F-VISUAL-04`, `F-EXPORT-01`, `02`, `06`.

## S-TASK-PROGRESS: 긴 작업 상태

- 작업 이름, 대상과 현재 단계
- 진행 막대와 백분율 또는 계산 중 상태
- 경과 시간과 1.0 예상 남은 시간
- 취소 버튼
- 완료 시 결과 파일 열기 또는 위치 열기
- 실패 시 요약, 해결 행동과 상세 정보 진입

짧은 작업에는 상태 표시줄과 알림만 사용하고, 사용자가 기다리거나 취소할 필요가 있는
작업은 작업 패널에 유지한다. 다른 편집을 허용하는 백그라운드 작업과 프로젝트를 잠가야 하는
출력을 명확히 구분한다.

연결 기능: `F-MEDIA-09`, `F-EXPORT-03`~`07`, `F-EXPERIENCE-01`.

## S-MISSING-MEDIA: 누락 미디어

- 누락 파일명과 마지막 경로
- 영향을 받는 미디어 및 클립 수
- MVP 행동: 누락 상태로 열기, 프로젝트 열기 취소
- 1.0 행동: 개별 파일 찾기, 폴더에서 일괄 찾기, 선택 항목 건너뛰기
- 잘못된 파일을 선택했을 때 불일치 이유

연결 기능: `F-MEDIA-06`, `07`, `F-PROJECT-04`, `F-EXPERIENCE-02`.

## S-RECOVERY: 자동 저장 복구

- 프로젝트명과 정상 저장 시각
- 자동 저장본 시각과 변경 요약
- 자동 저장본 열기, 정상 저장본 열기, 나중에 결정
- 복구본을 정상 저장 파일에 즉시 덮어쓰지 않는 안내

연결 기능: `F-PROJECT-07`, `08`, `09`.

## S-NARRATION: 내레이션 녹음

- 입력 장치 선택과 입력 수준
- 시작 위치와 현재 녹음 시간
- 녹음 시작, 일시 정지, 완료와 취소
- 완료 후 재생, 다시 녹음과 프로젝트에 추가
- 권한 거부, 장치 없음과 저장 실패 상태

연결 기능: `F-AUDIO-07`, `08`, `09`, `F-EXPERIENCE-01`, `02`.

## S-ONBOARDING: 시작 안내

- 첫 영상 만들기의 가져오기, 배치, 자르기, 저장과 출력 흐름
- 사용자가 언제든 건너뛰고 다시 열 수 있는 행동
- 예제 프로젝트 및 자산의 출처와 사용 범위
- 화면을 가리는 장기 투어보다 현재 UI를 가리키는 짧은 단계

연결 기능: `F-EXPERIENCE-06`.

## S-RUNTIME: Windows 실행 준비 및 진단

별도 네이티브 런처 창이며 편집기 레이아웃에 포함하지 않는다.

- 환경 상태: 준비되지 않음, 준비 중, 준비됨, 복구 필요
- uv, Python, 잠금 환경, FFmpeg와 ffprobe 상태
- 환경 구성 또는 복구
- 앱 옵션과 실행
- 진단 요약과 로그 열기
- 설치, 업데이트와 제거 진입

연결 기능: `F-RUNTIME-01`~`06`.

## S-MESSAGE와 S-SYSTEM-FILE

### 공통 메시지

- 저장하지 않은 변경 확인
- 보관함에서 사용 중인 미디어 제거 영향 확인
- 지원하지 않는 파일과 부분 가져오기 결과
- 명령 수행 불가 이유
- 출력 실패와 다음 행동

기본 버튼은 가장 안전하고 일반적인 행동으로 정하며 버튼 문구에 실제 결과를 쓴다. 예를
들어 `예`, `아니요`보다 `저장하고 닫기`, `저장하지 않고 닫기`, `취소`를 사용한다.

### 운영체제 파일 대화상자

미디어 가져오기, 프로젝트 열기·저장, 누락 파일 찾기와 출력 위치 선택은 운영체제 파일
대화상자를 사용한다. 목업에서는 고정된 샘플 결과를 반환하되 실제 화면의 진입 및 취소
경로를 동일하게 유지한다.
