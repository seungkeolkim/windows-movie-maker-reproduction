## 목적과 범위

W-05는 승인된 미리 보기 화면의 색상 캔버스와 100ms 가짜 타이머를 실제 프로젝트 시간축과
FFmpeg 영상·사진 프레임 디코딩으로 교체한다. 재생, 일시 정지, 탐색, 이전·다음 프레임과
`Space` 단축키가 같은 시간축을 사용하며 W-04 편집 직후 현재 프로젝트를 다시 해석한다.

이번 작업은 시각 프레임만 디코딩한다. 원본 영상 소리와 음악 믹싱은 W-06, MP4 출력은 W-07,
전환·효과와 프록시는 후속 작업이다. 프로젝트 JSON 스키마와 명령 이력에는 재생 위치, 디코딩
요청, PNG 프레임 또는 오류 상태를 추가하지 않는다.

## 프로젝트 시간과 클립 선택

- 재생 위치의 기준 값은 W-01 `ProjectTime`이며 UI 밀리초는 표시와 슬라이더 어댑터에서만
  변환한다.
- 시각 클립은 `[timeline_start, timeline_end)` 반열린 구간으로 해석한다. 정확한 경계에서는
  뒤 클립의 첫 프레임을 표시한다.
- 프로젝트 끝 위치에서는 마지막 시각 클립의 source out 바로 앞에 있는 마지막 표시 가능
  프레임을 유지한다. 시각 클립이 없으면 빈 미리 보기를 표시한다.
- 현재 프로젝트의 불변 `Project` 값을 요청마다 읽는다. 저장된 UI 목업 클립에서 별도
  프로젝트를 재구성하지 않는다.

프로젝트 위치 `T`, 클립 시작 `C`, source in `I`, 재생 속도 `R`일 때 요청 source 위치 `S`는
다음과 같다.

```text
local = clamp(T - C, 0, clip.duration)
S = I + local * R
```

모든 곱셈과 나눗셈은 정수와 `Fraction`으로 수행한다. 영상은 대표 영상 스트림의 평균
프레임률, 없으면 time base 경계에서 `S` 이하의 마지막 프레임을 선택한다. 사진은 source 0의
첫 프레임을 사용한다. 계산은 매번 미디어 원점과 절대 프레임 인덱스에서 시작하므로
24000/1001, 30000/1001과 60000/1001fps에서도 반복 덧셈 오차를 만들지 않는다.

## 원본 PTS와 FFmpeg 경계

디코딩 요청은 원본 경로, 대표 영상 스트림 인덱스, 상대 source 위치, 원본 `time_base`와
`start_pts`를 함께 보존한다. 상대 source 위치를 스트림 PTS로 바꿀 때에는 다음 식을 사용한다.

```text
source_pts = start_pts + floor(source_seconds / time_base)
```

`start_pts`가 없으면 0으로 본다. FFmpeg에는 source 위치를 소수점 9자리 이하의 정확한 상대
초 문자열로 전달하고, 입력 스트림을 명시적으로 선택해 PNG 한 프레임만 stdout으로 받는다.
경로와 필터를 포함한 모든 값은 셸 문자열이 아닌 argv 항목으로 전달하며 `shell=False`, 쓰기
불가능한 stdin, stdout/stderr 캡처를 사용한다. 원본 파일은 읽기 전용 입력이며 출력·임시
미디어·DB를 만들지 않는다.

디코딩 성공은 요청 식별자, 프로젝트 ID, 클립 ID, source 위치·PTS와 PNG 바이트를 반환한다.
빈 출력이나 잘못된 PNG는 성공으로 취급하지 않는다.

## 재생 시간축과 프레임 이동

- 재생 시 단조 증가 시계의 실제 경과 나노초를 직전 위치에 더한다. Qt 타이머 간격을 프로젝트
  시간으로 간주하지 않는다.
- 일시 정지는 현재 정확한 위치를 유지한다. 탐색과 프레임 이동은 먼저 일시 정지한다.
- 끝에서 재생하면 0으로 돌아가 시작하며, 재생 중 끝에 도달하면 끝 위치를 표시하고 멈춘다.
- 이전·다음 프레임은 현재 클립의 평균 프레임률 또는 time base에서 절대 경계를 계산한다.
  클립 경계를 넘으면 인접 시각 클립의 마지막 또는 첫 프레임으로 이동한다.
- 편집, undo/redo, 새 프로젝트와 열기 뒤에는 위치를 새 프로젝트 길이 안으로 제한하고 같은
  위치의 프레임을 새 프로젝트 값으로 다시 요청한다.

재생과 탐색은 `Project`, `CommandExecutor`, dirty 기준값을 바꾸지 않는 세션 상태다. 미리
보기 음소거도 W-06 전까지 프로젝트 오디오 속성과 무관한 세션 값으로 유지한다.

## 동시성, 최신 요청과 취소

FFmpeg 실행은 제한된 작업자 스레드에서 수행하고 Qt UI 스레드에서는 프로세스 완료를 기다리지
않는다. 각 요청은 단조 증가하는 세대 번호와 취소 이벤트를 가진다.

1. 새 탐색·재생 프레임 요청이 들어오면 이전 요청의 취소 이벤트를 설정한다.
2. 실행 중 FFmpeg 프로세스는 취소를 관찰하면 terminate 후 제한 시간 안에 끝나지 않을 때
   kill하고 stdout/stderr를 회수한다.
3. 완료 콜백은 현재 세대와 일치하고 서비스가 열려 있을 때만 Qt 신호로 전달한다.
4. 취소가 늦거나 프로세스가 이미 끝났더라도 오래된 세대의 성공·실패 결과는 폐기한다.
5. 새 프로젝트·프로젝트 열기, 창 닫기와 서비스 종료은 모든 요청을 취소하고 작업자를
   정리한다. 종료 뒤 콜백은 UI를 갱신하지 않는다.

재생 타이머는 최신 프로젝트 위치를 계속 표시할 수 있지만 동시에 유효한 디코딩 작업 수는
제한한다. 같은 프로젝트·클립·source 위치의 성공 프레임은 작은 세션 메모리 캐시로 재사용할
수 있으며 프로젝트나 JSON에 저장하지 않는다.

## 오류와 사용자 피드백

미리 보기 실패는 다음 타입을 구분한다.

| 오류 코드 | 의미와 다음 행동 |
| --- | --- |
| `source_not_found` | 원본이 이동·삭제됨. 누락 미디어 화면에서 다시 연결하도록 안내한다. |
| `ffmpeg_not_found` | FFmpeg 실행 파일을 찾을 수 없음. 실행 환경 점검을 안내한다. |
| `timeout` | 제한 시간 안에 프레임을 읽지 못함. 다시 시도하거나 다른 파일을 사용하도록 안내한다. |
| `process_failed` | 손상·미지원 코덱 등으로 FFmpeg가 실패함. 파일과 FFmpeg 지원을 확인하도록 안내한다. |
| `invalid_frame` | 결과가 비어 있거나 PNG가 아님. 해당 프레임을 표시할 수 없다고 안내한다. |
| `internal_error` | 주입 서비스의 계약 밖 실패. 현재 프로젝트를 유지하고 다시 시도하도록 안내한다. |

실패 시 마지막 정상 프레임을 새 클립의 프레임인 것처럼 남기지 않고 오류 플레이스홀더를
표시한다. 취소와 오래된 결과 폐기는 사용자 오류로 표시하지 않는다. 모든 실패 경로에서
프로젝트, 명령 이력, dirty, 원본 파일과 저장 파일은 변하지 않는다.

## UI 연결

- 미리 보기 배지는 `실제 프레임`으로 바꾸고 시작 화면은 가져오기·저장·편집·미리 보기가
  실제이며 오디오·출력은 후속임을 설명한다.
- 캔버스는 디코딩한 PNG를 현재 영역에 비율 유지하여 표시하고 크기 변경 시 원본 PNG에서
  다시 스케일한다.
- 슬라이더, 시간 레이블, 타임라인 재생 헤드와 디코딩 요청은 동일한 `ProjectTime`에서 나온다.
- 재생 버튼과 `Space`는 동일한 toggle 경계를 호출한다. 이전·다음 프레임 버튼은 실제 source
  경계를 사용하며 사용할 시각 클립이 없으면 비활성화한다.
- 누락·디코딩 중·실패 상태는 클립명과 원인, 가능한 다음 행동을 캔버스와 상태 표시줄에
  한국어로 표시한다.

## 필수 자동 검증

- 영상·사진 첫 프레임, 인접 클립 경계와 프로젝트 끝 프레임
- source in, 유리수 재생 속도와 24000/1001, 30000/1001, 60000/1001fps 변환
- time base와 start PTS를 포함한 source PTS 계산과 FFmpeg argv
- 재생·일시 정지·탐색·끝 처리, 이전·다음 프레임과 `Space`
- 연속 탐색의 오래된 응답 폐기, 프로세스 취소·강제 종료와 서비스 정리
- W-04 편집·undo/redo 및 W-03 저장·열기 뒤 프레임·재생 헤드·전체 길이 일치
- 누락·손상·미지원·빈 프레임 실패에서 프로젝트·이력·dirty 불변
- 미리 보기 전후 원본 파일 SHA-256, 크기와 수정 시간 불변
- W-01~W-04와 기존 Qt UI 전체 회귀
