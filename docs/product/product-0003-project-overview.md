# PRODUCT-0003: 제품 개요, 로드맵과 개발 상태

- 문서 번호: PRODUCT-0003
- 상태: 승인됨
- 목적: 루트 README에서 분리한 제품 배경, 목표, 범위, 로드맵과 구현 상태를 관리한다.

## 프로젝트 배경

Windows Movie Maker는 개인 영상과 사진을 간단히 편집하고 공유할 수 있게 해 주던
프로그램이었다. Windows Essentials 2012는 2017년 1월 10일 지원이 종료됐고 Microsoft의
공식 다운로드도 중단됐다. 이 프로젝트는 원본 설치 파일을 재배포하지 않고 핵심 사용 경험을
새로 구현한다.

복각의 기준은 다음 두 세대에서 가져온다.

- Windows XP/Vista판의 미디어 모음, 미리 보기, 스토리보드와 타임라인 구성
- Movie Maker 2012의 오디오 파형, 별도 내레이션 트랙, 오디오 강조(더킹), H.264 출력
- 현재 환경에서 기대되는 자동 저장, 프로젝트 복구와 다양한 미디어 입력

두 방식의 장점을 취하되 특정 버전의 화면을 픽셀 단위로 복사하지 않는다.

## 프로젝트 목표

1. 파일을 끌어다 놓은 뒤 자르기, 나누기와 순서 변경만 알아도 결과물을 만들 수 있게 한다.
2. 모든 편집을 비파괴 방식으로 기록하고 가져온 원본 파일을 수정하지 않는다.
3. 가져오기, 편집, 미리 보기, 프로젝트 저장과 동영상 내보내기가 끊김 없이 동작하게 한다.
4. 전문 NLE의 무제한 트랙보다 가정용 영상, 학교 과제와 짧은 기록물에 필요한 기능을
   명확하게 제공한다.
5. 최소한 MP4(H.264 영상/AAC 오디오)를 지원하고 코덱 차이를 가능한 한 드러내지 않는다.

## 제공하려는 편집 경험

- 영상, 사진, 음악과 음성 파일을 파일 선택 또는 드래그 앤 드롭으로 가져오기
- 여러 영상과 사진을 원하는 순서로 배치하고 복제·이동·삭제하기
- 클립의 시작과 끝을 다듬거나 재생 헤드 위치에서 나누고 불필요한 구간 제거하기
- 영상 속도와 사진 표시 시간 조절하기
- 원본음, 배경 음악과 내레이션의 음량 및 페이드 조절하기
- 오디오 파형을 보며 장면 전환이나 컷 위치 맞추기
- 마이크로 내레이션을 녹음하거나 외부 음성 파일 추가하기
- 제목, 캡션, 크레딧, 전환과 기본 시각 효과 추가하기
- 화면 비율과 출력 해상도를 선택하고 전체 영상 미리 보기
- 프로젝트 저장·다시 열기와 자동 저장본 복구
- 완성 영상을 MP4 파일로 내보내기

기능별 MVP·1.0·이후 확장 경계는
[PRODUCT-0002: 제품 기능 인벤토리](product-0002-feature-inventory.md)를 기준으로 한다.

## 핵심 편집 모델

편집 결과는 원본 파일 자체가 아니라 프로젝트 안의 명령으로 저장한다.

```text
미디어 보관함 ──끌어놓기──▶ 스토리보드/타임라인 ──재생──▶ 미리 보기
                                  │
                     분할 · 트리밍 · 순서 · 속도
                     음악 · 내레이션 · 자막 · 전환
                                  │
                                  ▼
                         MP4 동영상 내보내기
```

- 비디오/사진 트랙: 장면이 순서대로 이어지는 주 스토리 라인
- 음악 트랙: 프로젝트 전반의 배경 음악
- 내레이션 트랙: 음성 설명과 효과음
- 텍스트 레이어: 제목, 장면 캡션과 엔딩 크레딧
- 전환: 인접한 두 장면 사이에만 적용되는 효과

초기 버전은 이 고정 구조를 사용한다. 무제한 비디오 레이어는 범위를 크게 복잡하게 만들기
때문에 1.0 목표에 포함하지 않는다.

## 대표 사용 시나리오

### 여행 영상 만들기

1. 휴대폰 영상과 사진을 가져온다.
2. 장면을 촬영 순서대로 놓고 흔들린 앞뒤 구간을 자른다.
3. 사진 표시 시간을 조절하고 장면 사이에 페이드를 넣는다.
4. 배경 음악과 장소 캡션을 추가한다.
5. 1080p MP4로 내보낸다.

### 강의·설명 영상 만들기

1. 화면 녹화 영상을 가져와 실수한 부분을 분할해 삭제한다.
2. 재생 속도를 조절하고 마이크로 내레이션을 녹음한다.
3. 말하는 동안 배경 음악이 자동으로 작아지게 설정한다.
4. 제목과 핵심 설명 캡션을 추가해 MP4로 저장한다.

## 제품 원칙

- 버튼 이름과 동작은 처음 사용하는 사람도 예측할 수 있어야 한다.
- 편집 조작 뒤 미리 보기는 즉시 갱신되어야 한다.
- 프로젝트에는 미디어 경로, 편집점과 효과 설정만 저장하고 원본을 복제하지 않는다.
- 미디어 파일이 이동돼도 프로젝트를 망가뜨리지 않고 다시 찾을 수 있어야 한다.
- 내보내기 결과는 미리 보기와 시각적·청각적으로 일치해야 한다.
- 긴 작업은 진행률과 취소 방법을 보여 주고 실패 이유를 이해할 수 있게 설명한다.
- 키보드 탐색, 고대비와 자막 가독성 등 Windows 접근성 관례를 따른다.

## 로드맵

로드맵 단계는 날짜가 아니라 검증 가능한 결과를 기준으로 한다. 확정된 기술 선택은 ADR에
남기며, 검증 결과가 결정을 바꾸면 새 ADR로 변경 이유를 기록한다.

### 0단계 — 제품 정의와 기술 검증

- [x] Python, PySide6, uv 및 네이티브 런처를 기본 기술 구성으로 결정
- [x] 정확한 CPython 패치 버전과 최소 지원 uv 버전 확정
- [x] 런처에서 환경 점검과 애플리케이션 인자 전달 검증
- [ ] 디코딩·인코딩 엔진과 라이선스 검토
- [ ] 대표 입력 파일(H.264, HEVC, 가변 프레임률, MP3, WAV, JPEG, PNG) 호환성 실험
- [ ] 10분 분량 프로젝트의 프레임 정확도와 미리 보기 성능 검증
- [x] 프로젝트 파일 스키마와 비파괴 편집 모델 설계
- [ ] 원본을 참고하되 독자적인 이름·아이콘·시각 자산을 사용하는 디자인 가이드 수립

완료 조건은 가져온 영상의 임의 구간을 지정해 MP4로 다시 출력하는 수직 프로토타입이
동작하는 것이다.

### 1단계 — 편집 코어(MVP)

- [x] 새 프로젝트 및 영상·오디오·이미지 가져오기
- [x] 미디어 보관함과 항목 제거 및 기본 타임라인 UI
- [x] 실제 영상·사진 미리 보기 플레이어
- [x] 영상·오디오 클립 추가, 이동, 삭제, 분할과 트리밍
- [x] 편집 동작의 명령 실행 경계와 세션 행동 이력 구조
- [x] 사진 길이 및 영상 재생 속도 변경
- [x] 재생/일시 정지, 위치 탐색 및 실제 프레임 이동
- [x] 원본 오디오 음량 및 배경 음악 배치와 실제 미리 듣기
- [x] 프로젝트 저장/다른 이름으로 저장/열기와 누락 미디어 안내
- [x] 원본 비율·해상도 유지 또는 720p/1080p MP4 출력과 진행률·취소·오류 안내

완료 조건은 최소 두 영상과 한 음악 파일로 1분짜리 영상을 만들고, 앱을 재실행해 편집을
계속한 뒤 정상적인 MP4로 출력하는 것이다.

### 2단계 — Movie Maker다운 창작 기능(0.5)

- [x] 스토리보드와 확대 가능한 타임라인 보기, 프레임 단위 이동
- [x] 실행 취소/다시 실행과 안정적인 리플 편집
- [x] 같은 트랙 다중 선택, 클립 복제와 원자적 그룹 이동·삭제
- [x] 오디오 파형(W-10)
- [x] 페이드 인/아웃과 원본음·음악·내레이션 음량 믹서
- [x] 내레이션 파일 및 마이크 녹음
- [x] 제목, 캡션과 크레딧 편집기
- [x] 페이드와 대표 전환 효과
- [x] 회전, 맞춤/채움, 밝기와 기본 시각 효과

완료 조건은 여행 영상과 내레이션 강의 영상 시나리오를 외부 도구 없이 완성하고,
실행 취소와 복구가 데이터 손실 없이 동작하는 것이다.

### 3단계 — 성능·호환성·품질(0.8)

- [x] 프록시 미디어와 백그라운드 파형/썸네일 생성
- [ ] 가변 프레임률과 서로 다른 해상도·프레임률 혼합 처리
- [ ] 영상·음성 싱크 및 프레임 경계 테스트
- [x] 내레이션 우선 자동 더킹
- [ ] 출력 품질·해상도·프레임률 프리셋
- [ ] 장시간 내보내기 진행률 정확도, 취소 후 정리 및 오류 복구
- [ ] 키보드 단축키, 접근성, 다국어화 기반
- [x] Windows 설치·업데이트·제거 흐름

완료 조건은 60분 프로젝트의 편집·저장·재개·출력 안정성 시험을 통과하고 지원 형식과
알려진 제한 사항을 문서화하는 것이다.

### 4단계 — 1.0 배포

- [x] 대표 전환·효과·텍스트 애니메이션 세트 완성
- [ ] 성능 및 메모리 사용량 기준 충족
- [ ] 충돌 복구와 프로젝트 이전 버전 호환성 검증
- [ ] 신규 사용자용 온보딩과 예제 프로젝트
- [ ] 라이선스, 개인정보 처리와 서드파티 고지 정리
- [ ] 서명된 Windows 설치 패키지와 릴리스 노트 제공

완료 조건은 처음 사용하는 사람이 안내 없이 30분 안에 가져오기부터 1080p MP4 출력까지
완료하고 자동화된 핵심 편집/내보내기 회귀 테스트를 모두 통과하는 것이다.

### 1.0 이후 후보

- 영상 안정화와 간단한 색상 보정
- 테마 기반 자동 영화 만들기
- 사용자 정의 효과/전환 확장 시스템
- 추가 출력 코덱 및 하드웨어 인코딩 최적화
- 선택적 온라인 공유 연동

## 1.0에서 하지 않을 것

- 다중 카메라 편집, 무제한 영상 트랙과 노드 기반 합성
- 전문 색보정, 모션 그래픽과 DAW 수준의 오디오 처리
- 클라우드 계정이나 인터넷 연결을 요구하는 핵심 기능
- 원본 Windows Movie Maker 바이너리, 코드, 아이콘, 음원과 상표 자산의 포함 또는 재배포
- Microsoft의 기존 프로젝트 파일(`.mswmm`, `.wlmp`) 호환성 보장

기존 프로젝트 가져오기는 형식과 권리 문제를 별도로 검토한 뒤 향후 호환 기능으로 판단한다.

## 품질 목표

- 저장·자동 저장 중 원본 미디어나 정상 프로젝트가 손상되지 않을 것
- 같은 프로젝트를 반복 출력했을 때 컷 위치와 전체 길이가 일관될 것
- 미리 보기와 출력 파일 사이에 눈에 띄는 자막 위치·전환·음량 차이가 없을 것
- 지원 입력 파일은 성공적으로 가져오거나 실패 이유와 해결 방법을 표시할 것
- 앱 충돌 뒤 마지막 자동 저장 시점으로 복구할 수 있을 것

## 이름과 권리

이 저장소는 학습 및 보존적 재구현을 위한 비공식 독립 프로젝트이며 Microsoft와 제휴하거나
Microsoft의 승인을 받은 제품이 아니다. Windows와 Windows Movie Maker는 각 권리자의
상표일 수 있다. 정식 배포 전에는 혼동을 피할 독자적인 제품명을 정하고 원본 프로그램의 코드와
자산을 복사하지 않는다.

소프트웨어, 코덱, 기본 자산과 사용자 출력물의 권리 경계는
[POLICY-0001: 라이선스와 출력물 권리](../policies/policy-0001-licensing-and-output-rights.md)를
따른다.
