## 목적

이 문서는 W-02에서 실제 파일 선택·분석으로 교체된 보관함 경계와 W-03 실제 프로젝트
저장·열기 경계, 아직 실제 디코딩과 FFmpeg 출력 없이 MVP·1.0 화면 흐름을 검증하는 데이터,
상태, 사용자 동작과 전이 결과를 함께 정의한다.

목업은 버튼을 눌렀다는 알림만 보여 주는 정적 화면이 아니다. 가져오기, 타임라인 편집,
속성 변경, 재생, 저장과 출력의 가짜 상태가 서로 연결되어 사용자가 현재 결과와 다음 행동을
판단할 수 있어야 한다.

## 목업 범위와 실제 구현 경계

### 목업에서 구현하는 것

- 메모리 안의 샘플 프로젝트와 후속 기능용 샘플 미디어
- W-02 실제 미디어 가져오기·선택·안전한 제거 및 종류 필터
- 영상·사진·음악의 타임라인 배치
- 클립 선택, 순서 이동, 삭제, 분할, 트리밍, 길이와 속도 변경
- 원본음과 음악의 음량·음소거 변경
- 재생 위치, 재생/일시 정지와 프레임 이동 흉내
- 제목·캡션·크레딧, 전환, 내레이션과 시각 설정의 가짜 상태
- 선택 영상의 프록시 사용·해제와 고정된 준비 완료 상태
- W-03 실제 새 프로젝트·저장·다른 이름으로 저장·열기와 저장하지 않은 변경 확인
- 실행 취소·다시 실행 UI의 1.0 동작 시뮬레이션
- 원본 유지·720p·1080p 출력 설정과 가짜 진행·취소·완료·실패
- 누락 미디어, 복구, 녹음, 온보딩과 런타임 상태 대화상자
- 1024×640, 1280×720 및 1920×1080 레이아웃 렌더링

### 목업에서 구현하지 않는 것

- 누락 미디어 다시 연결용 실제 파일 대화상자
- 실제 파형·프록시 파일 생성
- 실제 영상 및 오디오 디코딩과 재생
- 실제 마이크 입력
- 미리 보기·출력용 FFmpeg 프로세스와 MP4 생성
- 실제 Windows 네이티브 런처, 설치 또는 업데이트

W-02 미디어 보관함과 W-03 프로젝트 파일을 제외한 실제 구현 경계의 행동은 고정된 샘플
결과와 명확한 `목업` 상태로 대체한다. 목업 메시지가 실제 작업이 완료된 것처럼 오해되지
않게 한다.

## 샘플 데이터

### 미디어 보관함

| ID | 종류 | 표시 이름 | 원본 정보 | 길이 | 목업 색상/상태 |
| --- | --- | --- | --- | --- | --- |
| `media-beach` | 영상 | `해변 산책.mp4` | 1920×1080, 30fps | 12초 | 파랑, 정상 |

| `media-music` | 오디오 | `여행 배경음악.mp3` | 44.1kHz 스테레오 | 30초 | 보라, 정상 |

| `media-broken` | 알 수 없음 | `손상된 파일.mov` | 분석 실패 | 알 수 없음 | 빨강, 오류 |

기본 새 프로젝트는 빈 보관함에서 시작한다. 주 `미디어 가져오기`는 실제 파일을 선택하며,
위 정상 항목 다섯 개는 `샘플 편집 프로젝트 불러오기` 개발 메뉴에서 제공한다. 오류·누락
항목도 목업 상태 메뉴에서 별도로 주입할 수 있다.

### 샘플 편집 프로젝트

`프로젝트 열기` 또는 `예제 프로젝트`는 다음 상태를 불러온다.

- 프로젝트명: `제주 여행 목업`
- 출력 화면: `원본 유지`, 1920×1080
- 영상·사진: 해변 산책 8초, 야시장 6초, 한라산 사진 5초
- 배경 음악: 0초부터 19초, 음량 55%
- 내레이션: 4초부터 12초, 음량 90%, 더킹 `보통`
- 캡션: `협재 해변`, 3초부터 6초
- 첫 장면과 둘째 장면 사이 페이드: 0.75초
- 전체 길이: 19초
- 저장 상태: 저장됨

## 프로젝트 및 저장 동작

| 상호작용 | 시작 상태 | 전이 결과 |
| --- | --- | --- |
| `I-PROJECT-NEW` | 저장됨 | 새 ID와 빈 고정 트랙의 실제 프로젝트 세션으로 교체 |
| `I-PROJECT-NEW` | 수정됨 | `M-PROJECT-UNSAVED-PROMPT`; 취소 시 변화 없음 |
| `I-PROJECT-OPEN` | 저장됨 | 선택한 JSON 전체 검증 성공 후 새 빈 이력 세션으로 교체 |
| `I-PROJECT-OPEN` | 수정됨 | 저장 확인 뒤 사용자가 선택하고 열기가 성공한 경우에만 교체 |
| `I-PROJECT-SAVE` | 경로 없음 | 실제 저장 위치를 선택하고 원자적 교체 성공 뒤 저장됨 처리 |
| `I-PROJECT-SAVE` | 경로 있음 | 같은 경로의 원자적 교체 성공 뒤 `is_dirty = false` |
| `I-PROJECT-SAVE-AS` | 항상 | 새 실제 경로를 선택하고 성공한 경우에만 현재 경로 변경 |

선택 취소와 저장·열기 실패는 프로젝트, 경로, 이름과 dirty 상태를 유지한다. 저장은 같은
디렉터리 임시 파일의 전체 기록, flush/fsync와 `os.replace` 순서로 완료하며 상세 계약은
[DESIGN-0005](../design/design-0005-project-persistence-contract.md)를 따른다.

## 미디어 동작

### 가져오기

1. `I-MEDIA-IMPORT`를 실행하면 운영체제 다중 파일 선택 창을 연다.
2. 선택한 각 파일을 ffprobe로 분석하고 성공 결과만 W-01 프로젝트 명령으로 추가한다.
3. 같은 정규화 원본 경로가 이미 있으면 다시 분석하거나 중복 항목을 만들지 않는다.
4. 일부 파일이 실패해도 성공 항목과 앞선 명령을 유지하고 파일별 이유를 보관함에 표시한다.
5. 영상과 사진의 썸네일 실패는 기본 종류 아이콘으로 격리한다.
6. 첫 성공 항목 또는 기존 중복 항목을 선택하고 보관함 필터를 `전체`로 전환한다.
7. 선택을 취소하면 프로젝트, 행동 이력과 수정됨 상태를 바꾸지 않는다.

목업 전용 상태 메뉴의 `샘플 편집 프로젝트 불러오기`와 오류 주입은 W-03 이후 화면을 계속
검증하기 위해 유지한다. 실제 W-02 경계는 DESIGN-0004를 따른다.

### 타임라인에 추가

- 영상과 사진은 주 스토리 라인의 끝에 추가한다.
- 음악은 음악 트랙의 0초 또는 기존 음악 뒤에 추가한다.
- `장소 설명.wav`는 샘플 역할에 따라 내레이션 트랙에, 그 밖의 오디오는 음악 트랙에
  추가한다. 메뉴의 명시적 내레이션 추가 경로도 같은 고정 트랙을 사용한다.
- 새 클립을 선택하고 재생 헤드를 클립 시작점으로 이동한다.
- 영상은 원본 길이, 사진은 5초의 기본 표시 길이를 사용한다.

### 보관함에서 제거

- 사용하지 않는 항목은 즉시 제거하고 원본 파일은 삭제되지 않는다고 알린다.
- 타임라인에서 사용 중인 항목은 영향을 받는 클립 수를 표시하고 제거를 거부한다.
- 사용자는 관련 클립을 먼저 제거한 뒤 다시 시도한다.
- 거부하면 선택, 프로젝트와 원본 파일을 그대로 유지한다.

## 타임라인 동작

### 선택과 재생 위치

- 클립을 선택하면 다른 단일 선택을 해제하고 해당 종류의 속성 페이지를 표시한다.
- 시각 클립을 선택하면 재생 헤드를 클립 시작으로 이동한다.
- 보관함을 선택하면 타임라인 선택을 해제하고 반대도 동일하다.
- 다중 선택은 1.0 목업에서 `Ctrl` 선택으로 시뮬레이션한다.

### 이동

- 목업은 `앞으로 이동`과 `뒤로 이동` 명령으로 시각 클립 순서를 바꾼다.
- 실제 끌기 삽입점은 타임라인 위젯 배선 단계에서 검증하며 현재 목업은 같은 결과를 만드는
  이동 버튼과 키보드 경로를 사용한다.
- 첫 클립의 앞으로 이동과 마지막 클립의 뒤로 이동은 비활성화한다.
- 이동 뒤 모든 시각 클립 시작 시간을 앞에서부터 다시 계산한다.
- 음악·내레이션·텍스트의 절대 시작 시간은 목업에서 유지한다.

### 분할

- 선택된 영상 또는 오디오 클립의 내부에 재생 헤드가 있을 때만 활성화한다.
- 경계에서 250ms 이내이면 분할하지 않고 이유를 표시한다.
- 앞 클립은 분할점까지, 뒤 클립은 분할점부터 원본 구간을 참조한다.
- 뒤 클립을 선택하고 재생 헤드는 분할 위치에 유지한다.
- 사진과 텍스트에는 분할을 제공하지 않는다.

### 삭제

- 선택된 클립을 해당 트랙에서 제거한다.
- 시각 클립 삭제 뒤 남은 클립은 빈 시간 없이 이어 붙인다.
- 연결할 수 없는 전환은 함께 제거한다.
- 재생 헤드가 새 전체 길이를 넘으면 끝 위치로 제한한다.

### 트리밍, 사진 길이와 속도

- 목업의 트리밍 입력은 0.5초 단위를 사용한다.
- 영상과 오디오는 최소 0.5초 구간을 남긴다.
- 사진 표시 길이는 1~30초, 기본 5초다.
- 속도 선택지는 0.5×, 1×, 1.5×, 2×다.
- 속도 변경 뒤 결과 길이는 원본 사용 길이를 배율로 나눈 값이다.
- 변경 뒤 전체 시간, 재생 헤드 범위와 출력 요약을 다시 계산한다.

### 실행 취소와 다시 실행

목업은 작은 상태 복사본으로 1.0 UI를 시뮬레이션할 수 있다. 이는 실제 구현 방식이 아니며
실제 편집 코어는 ADR-0002의 명령 구조를 사용한다.

- 편집 결과를 바꾸는 목업 행동마다 이전·다음 상태와 표시 이름을 기록한다.
- 실행 취소 뒤 해당 행동 이름과 결과를 상태 표시줄에 표시한다.
- 다시 실행은 취소했던 다음 상태를 복원한다.
- 실행 취소 뒤 새 편집을 수행하면 기존 다시 실행 후보를 제거한다.
- 새 프로젝트와 프로젝트 열기는 목업 이력을 비운다.

## 미리 보기 동작

- 재생은 100ms 목업 타이머마다 프로젝트 시간을 증가시킨다.
- 시각 클립 구간에 따라 캔버스 배경색, 클립명과 가짜 프레임 시간을 바꾼다.
- 사진은 같은 색상 프레임을 표시한다.
- 프로젝트 끝에 도달하면 `M-PREVIEW-ENDED`가 된다.
- 끝에서 다시 재생하면 0초로 이동하고 재생한다.
- 탐색 중에는 재생을 일시 정지한다.
- 프레임 이동 목업은 30fps 기준 약 33ms를 이동하되 실제 정확도를 주장하지 않고
  `목업 프레임 이동`이라고 표시한다.
- 미리 보기 음소거는 프로젝트의 원본음·음악 음량 값을 바꾸지 않는다.

## 속성 동작

- 숫자와 선택값이 바뀌면 `적용` 행동에서 하나의 목업 편집 명령으로 기록한다.
- 사용자가 `적용`을 누르기 전에 선택을 바꾸면 프로젝트 상태는 바뀌지 않고 새 선택의 값으로
  입력 필드를 다시 그린다.
- 음량은 0~100%, 트리밍은 유효 원본 구간, 사진 길이는 1~30초로 제한한다.
- 선택한 미디어가 누락이면 변경 가능한 편집 속성을 비활성화하고 다시 연결 행동을 표시한다.
- 텍스트 내용은 빈 값도 허용하지만 미리 보기에는 `텍스트를 입력하세요` 플레이스홀더를
  표시한다.

## 원본 유지 동작

1. `원본 유지`를 선택할 때 첫 영상 클립, 없으면 첫 사진 클립을 기준으로 찾는다.
2. 기준 미디어가 없으면 선택을 비활성화하고 `먼저 영상이나 사진을 추가하세요`를 표시한다.
3. 회전 메타데이터를 적용한 기준 비율과 해상도를 프로젝트 화면에 저장한다.
4. `reference_asset_id`와 저장된 화면 크기는 이후 클립 순서 변경이나 제거로 자동 변경하지
   않는다.
5. 기준 미디어가 보관함에서 제거돼도 화면 크기는 유지하고 기준 미디어 이름만 `제거됨`으로
   표시한다.
6. 다른 비율의 클립은 MVP에서 전체 내용이 보이는 맞춤과 중립 배경을 사용한다.
7. 720p는 1280×720, 1080p는 1920×1080으로 즉시 요약을 갱신한다.

## 1.0 창작 기능의 목업 동작

- **스토리보드:** 시각 클립을 같은 순서의 큰 카드로 바꾸고 오디오·텍스트 트랙은 요약
  표시한다.
- **복제:** 선택 클립 바로 뒤에 같은 속성의 새 ID를 삽입한다.
- **파형:** 실제 분석 대신 반복되는 장식 파형을 표시하고 `목업 파형` 도구 설명을 사용한다.
- **프록시:** 정상 영상에서 사용 여부를 바꾸면 파일 없이 즉시 `준비됨 · 목업 대체본`으로
  표시하고 보관함과 상태 표시줄의 준비 개수를 갱신한다.
- **내레이션:** 녹음 대화상자의 가짜 입력 수준과 타이머를 진행하고 완료하면 샘플 음성을
  내레이션 트랙에 추가한다.
- **텍스트:** 제목은 시작, 캡션은 재생 헤드, 크레딧은 프로젝트 끝을 기본 위치로 사용한다.
- **전환:** 선택한 인접 경계에 0.75초 페이드를 적용하고 속성에서 길이를 바꾼다.
- **맞춤/채움:** 캔버스 플레이스홀더의 여백 또는 잘림 설명을 바꾼다.
- **회전:** 썸네일 자체를 변환하지 않고 회전 각도와 캔버스 안내를 갱신한다.
- **효과:** 미리 보기 색조와 효과 이름을 바꾼다.
- **자동 저장/복구:** 실제 디스크 저장 없이 복구 대화상자 상태만 재현한다.

## 출력 동작

### 설정

- 출력 설정을 열 때 현재 프로젝트 화면과 길이를 요약한다.
- 원본 유지 선택은 기준 미디어 이름, 비율과 해상도를 표시한다.
- 720p와 1080p는 16:9 고정 해상도를 표시한다.
- 1.0 프레임률과 품질은 목업 값만 바꾸고 예상 크기 문구를 갱신한다.
- 시각 클립이 없으면 출력 진입을 비활성화한다.

### 진행

- 저장 시작 뒤 200ms마다 5%씩 증가하여 약 4초에 완료한다.
- 진행 중 편집 명령과 중복 출력은 비활성화한다.
- 취소는 확인 뒤 다음 타이머 주기에서 `M-EXPORT-CANCELLED`로 전환한다.
- 완료 결과는 `C:\Videos\제주 여행 목업.mp4`라는 가짜 경로를 표시한다.
- 결과 열기 행동은 파일을 만들지 않고 `목업 결과이므로 파일을 열지 않았습니다`를 표시한다.

### 실패 주입

목업 전용 메뉴에서 다음 출력 한 번 실패를 선택할 수 있다.

- 출력 위치에 쓸 수 없음
- FFmpeg를 찾을 수 없음
- 디스크 공간 부족

실패 뒤 설정으로 돌아가도 사용자가 선택한 출력 설정은 유지한다.

## 목업 전용 상태 메뉴

실제 제품에는 포함하지 않을 `목업 상태` 메뉴를 개발 목업에서만 제공한다.

- 샘플 편집 프로젝트 불러오기
- 빈 프로젝트로 초기화
- 누락 미디어 추가
- 가져오기 부분 실패 표시
- 다음 출력 실패 예약
- 자동 저장 복구 대화상자 열기
- 더 새 버전 프로젝트의 안전한 열기 거부 메시지
- 온보딩 열기
- 런타임 상태 열기

각 항목 이름에 `목업`을 표시하고 실제 제품 기능과 시각적으로 구분한다.

## 대표 시나리오 전이

### SC-MVP-01

```text
M-PROJECT-EMPTY
  → 미디어 가져오기
M-LIBRARY-READY
  → 영상 두 개와 음악 추가
M-TIMELINE-READY / M-PROJECT-DIRTY
  → 트리밍·순서·음량 변경
M-PREVIEW-PLAYING
  → 저장
M-PROJECT-READY
  → 출력 설정·시작
M-EXPORT-RUNNING
  → M-EXPORT-COMPLETE
```

### SC-MVP-02

```text
샘플 영상 선택
  → 내부 위치 탐색
  → 분할
  → 다음 내부 위치 탐색
  → 분할
  → 가운데 클립 삭제
  → 남은 결과 재생
```

### SC-MVP-03

```text
수정됨 프로젝트
  → 저장
  → 새 프로젝트
  → 프로젝트 열기
  → 샘플 저장 상태와 누락 미디어 확인
```

### SC-ERROR-01

```text
누락/오류 상태 주입
  → 항목과 영향 확인
  → 누락 상태로 편집 유지
  → 다음 출력 실패 예약
  → 출력 실패와 해결 행동 확인
```
