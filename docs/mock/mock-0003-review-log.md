## 결론

MVP와 1.0 기능을 위한 화면 구조, 요소별 동작, 목업 상태 변화와 실제 서비스 연결 경계를
`UI-MOCK-BASELINE-1`로 승인한다. 대표 작업은 한 편집기 안에서 `가져오기 → 배치 → 편집 →
미리 보기 → 프로젝트 저장 → 동영상 저장` 순서로 발견하고 수행할 수 있다. 빈 상태, 누락,
부분 실패, 저장 확인, 출력 진행·취소·완료·실패와 복구 화면도 작업 맥락을 잃지 않고 확인할
수 있다.

기준선 승인 당시에는 실제 미디어 재생, 디스크 프로젝트 저장이나 MP4 렌더링을 완료하지
않았다. 현재 W-03에서 디스크 프로젝트 저장을, W-04에서 MVP 타임라인 편집과 명령 기반
undo/redo를, W-05에서 실제 영상·사진 미리 보기를, W-06에서 영상 원본음·음악 믹싱과 미리
듣기를 서비스로 교체했다. 다음 구현은 승인된 화면 계약을 유지하면서 출력의 가짜 결과를
교체한다.

## 승인한 화면·동작 결정

### 편집기 구조

- 기본 화면은 왼쪽 보관함, 중앙 미리 보기, 오른쪽 속성과 아래 타임라인의 한 창 구조다.
- 보관함과 속성은 접을 수 있으나 선택과 편집 상태를 잃지 않는다.
- 1024×640에서는 속성을 먼저 접고, 1280×720부터 세 패널과 타임라인을 함께 표시한다.
- 메뉴는 모든 MVP·1.0 기능의 안정적인 경로이고 도구 모음은 자주 쓰는 MVP 명령과 1.0
  실행 취소·다시 실행 자리만 제공한다.

### 편집 모델의 화면 표현

- 시각 미디어는 한 개의 순차 스토리 라인에 놓는다.
- 원본 오디오는 영상 클립 속성이고 음악, 내레이션과 텍스트는 용도가 고정된 별도 트랙이다.
- 단일 선택은 종류에 맞는 속성을, 다중 선택은 선택 수와 공통 명령만 표시한다.
- 이동·삽입·삭제 뒤 시각 클립은 빈 시간 없이 이어지고, 절대 시간 기반 음악·내레이션·텍스트
  관계는 실제 리플 정책에서 명시적으로 처리한다.

### 프로젝트 화면과 출력

- `원본 유지`를 선택하는 시점의 첫 영상, 영상이 없으면 첫 사진을 기준으로 회전 메타데이터를
  적용한 화면 비율과 해상도를 고정한다.
- 기준 항목의 순서 변경이나 제거로 프로젝트 화면을 자동 변경하지 않는다.
- 다른 비율은 MVP에서 전체 내용이 보이는 `맞춤`과 중립 여백을 사용하고 1.0에서 `채움`을
  선택할 수 있다.
- 고정 프리셋은 720p 1280×720과 1080p 1920×1080이며 MP4 H.264/AAC를 기본으로 한다.

### 피드백과 안전

- 제목의 `*`, 선택 테두리, 재생 시간, 상태 표시줄과 작업 패널이 현재 상태를 함께 보여 준다.
- 사용할 수 없는 명령은 필요한 조건을 도구 설명이나 상태 메시지로 말한다.
- 저장하지 않은 변경과 출력 취소는 결과를 말하는 동사형 선택지를 쓴다. 사용 중 미디어는
  관련 클립 수를 알리고 클립을 먼저 제거하도록 안전하게 거부한다.
- 원본 파일을 수정·이동·삭제하는 UI는 제공하지 않는다.
- 실제 구현에서 지속적인 프로젝트 변경은 ADR-0002의 명령 실행 경계를 통과한다.

`W-01`은 2026-09-07에 완료했다. 정수 나노초 시간과 유리수 프레임률, 불변 프로젝트·클립
모델, 전체 스냅샷을 사용하지 않는 명령·역명령 이력을 구현했다. 명령 실행, undo/redo,
이력 분기와 모든 실패 경계에서 프로젝트와 이력 위치가 원자적으로 유지됨을 자동 검증했다.
상세 계약과 DB 미사용 판단은 [DESIGN-0003](../design/design-0003-project-core-contract.md)과
[ADR-0003](../decisions/adr-0003-project-core-state-and-storage.md)에 기록한다.

`W-02`는 2026-09-07에 완료했다. 네이티브 다중 파일 선택, ffprobe 분석, 원본 스트림 시간
메타데이터, 명령 기반 부분 성공·중복 방지·안전한 제거와 메모리 썸네일을 실제 서비스로
연결했다. 상세 계약과 검증 결과는 [DESIGN-0004](../design/design-0004-media-library-contract.md)에
기록한다.

`W-03`은 2026-09-07에 완료했다. `schema_version` 1의 UTF-8 JSON에 W-01 프로젝트와 W-02
스트림 메타데이터를 손실 없이 기록하고, 같은 디렉터리 임시 파일의 flush/fsync 뒤
`os.replace`로 교체한다. 전체 파싱과 도메인 검증 성공 후에만 새 빈 이력 세션으로 전환하며,
실패·취소와 누락 원본의 안전 경계를 실제 Qt 파일 대화상자에 연결했다. 상세 계약과 검증은
[DESIGN-0005](../design/design-0005-project-persistence-contract.md)에 기록한다.

`W-04`는 2026-09-07에 완료했다. 고정 트랙 추가, 시각 이동·삭제·리플, 영상·오디오 분할과
트리밍, 사진 길이, 유리수 영상 속도를 실제 명령으로 연결했다. Qt 단축키와 메뉴도 공용
실행기의 undo/redo를 사용하며 W-03 JSON 왕복과 원본 비수정을 함께 검증했다. 상세 계약과
전체 139개 테스트 결과는 [DESIGN-0006](../design/design-0006-timeline-editing-contract.md)에

`W-05`는 2026-09-08에 완료했다. 단조 시계 기반 프로젝트 재생 위치, source in과 유리수 속도,
평균 프레임률·time base·start PTS를 보존하는 프레임 매핑과 취소 가능한 FFmpeg PNG 디코딩을
구현했다. 연속 탐색은 최신 요청만 Qt UI에 반영하고 프로젝트 교체·종료 시 작업과 프로세스를

`W-06`은 2026-09-11에 완료했다. 정수 백분율 음량과 별도 음소거를 스키마 1의 호환 선택
필드로 저장하고, 영상 원본음·음악의 source 구간·속도·절대 배치를 48 kHz 스테레오 공통
FFmpeg 그래프로 해석한다. 미리 듣기는 W-05 단조 시계에 맞춰 늦게 도착한 PCM 앞부분을
버리고 재생·탐색·편집·교체·종료에서 오래된 프로세스와 장치를 취소한다. 실제 44.1 kHz AAC와
32 kHz PCM을 혼합하고 전체 189개 테스트를 통과했다. 상세 계약은
[DESIGN-0008](../design/design-0008-audio-mixing-contract.md)에 기록한다.

`W-07`은 2026-09-12에 완료했다. 불변 프로젝트 스냅샷의 시각 트랙과 W-06 오디오 그래프를
30fps H.264/AAC MP4로 만들고, 기계 진행률·취소·전체 디코딩 검증·같은 폴더 원자적 게시를

호환 다중 선택과 스토리보드·확대·드롭·키보드 상태를 비지속 세션 경계로 분리했다. 상세 계약은

오디오, 출력과 고급 타임라인 계약을 재사용한다.

## 기준선 변경 규칙

- 버튼 이름, 화면 위치나 상태 전이가 달라지면 관련 `F-`, `S-`, `E-`, `I-`, `M-` 항목과
  테스트를 같은 변경에서 갱신한다.
- MVP와 1.0 범위가 달라지면 PRODUCT-0002를 먼저 변경하고 사용자 시나리오 영향을 검토한다.
- 명령, 저장, 시간축 또는 런처의 장기 결정이 달라지면 기존 ADR을 덮어쓰지 않고 후속 ADR을
  추가한다.
- 기준 화면은 구조 변경 때만 재생성하고 색상이나 운영체제 렌더 차이만으로 기능 승인을
  변경하지 않는다.
- 실제 서비스가 연결된 기능은 화면의 `목업` 표시와 해당 상태 주입 경로를 제거하되 오류
  재현용 개발 도구는 테스트 전용 경계로 유지할 수 있다.
