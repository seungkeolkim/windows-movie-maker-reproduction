# 라이선스와 출력물 권리

이 문서는 프로젝트의 소프트웨어 라이선스와 사용자가 만든 영상 출력물의 권리를 구분하기 위한 정책 초안입니다. 정식 배포 전의 기술·자산 검토 기준이며 법률 자문을 대신하지 않습니다.

## 현재 상태

- 저장소 자체에 적용할 오픈소스 라이선스는 아직 결정되지 않았습니다.
- 저장소에는 `LICENSE` 파일이 없고 `pyproject.toml`에도 프로젝트 라이선스가 선언되어 있지 않습니다.
- Python 런타임, PySide6/Qt 및 FFmpeg 실행 파일을 저장소나 현재 배포물에 포함하지 않습니다.
- FFmpeg와 ffprobe는 사용자가 별도로 설치하며, 프로젝트는 발견된 실행 파일을 외부 프로세스로 사용하도록 설계되어 있습니다.
- 현재 애플리케이션에는 출력물에 들어갈 기본 음악, 영상, 글꼴, 템플릿 또는 기타 미디어 자산이 없습니다.

프로젝트 라이선스가 확정되기 전까지 저장소의 코드와 문서를 특정 오픈소스 라이선스로 배포할 수 있다고 가정해서는 안 됩니다.

## 출력물에 대한 원칙

PySide6/Qt, FFmpeg 및 Python 의존성의 소프트웨어 라이선스는 일반적으로 프로그램과 라이브러리의 사용·수정·연결·재배포를 규율합니다. 사용자가 자신의 데이터를 프로그램으로 변환했다는 사실만으로 출력물에 그 소프트웨어 라이선스가 자동으로 적용되지는 않습니다.

이 프로젝트는 사용자가 제공한 미디어로 생성한 프로젝트 파일과 출력 미디어에 소프트웨어 라이선스를 추가로 부과하거나 그 권리를 주장하지 않습니다. 다만 이 정책은 사용자가 보유하지 않은 권리를 새로 부여하지 않으며, 입력 자료나 출력물에 포함된 제3자 콘텐츠의 조건보다 우선하지 않습니다.

| 대상 | 출력물에 대한 영향 |
| --- | --- |
| 프로젝트의 애플리케이션 코드 | 코드가 출력물에 복제되지 않는 일반적인 영상 내보내기에는 자동 적용되지 않음 |
| PySide6/Qt 및 Python 패키지 | 애플리케이션 배포 조건이며 일반적인 영상 출력물에는 자동 적용되지 않음 |
| FFmpeg 및 선택적으로 활성화된 GPL 구성 요소 | FFmpeg 빌드와 애플리케이션 배포 조건에 영향을 줄 수 있지만 인코딩된 영상에 GPL/LGPL을 자동 적용하지 않음 |
| 사용자 영상·사진·음악·글꼴·템플릿 | 해당 콘텐츠의 이용 조건이 출력물과 그 배포에 직접 영향을 줄 수 있음 |
| 프로그램이 기본 제공하는 미디어 자산 | 출력물 사용을 허용하는 자산 라이선스가 필요하며 자산별 조건이 적용될 수 있음 |
| H.264/AAC 등의 코덱 특허 | 출력물의 저작권 라이선스와 별개이며 제품·서비스·지역·이용 형태에 따라 검토가 필요함 |

## 소프트웨어 라이선스가 출력물에 관계될 수 있는 예외

프로그램을 실행했다는 이유가 아니라 라이선스 대상 저작물이 실제 출력물에 포함될 때는 그 조건을 확인해야 합니다. 예를 들면 다음과 같습니다.

- 애플리케이션에 포함된 영상, 음악, 효과음, 이미지 또는 템플릿을 결과물에 삽입하는 경우
- 라이선스 제한이 있는 글꼴로 자막이나 제목을 렌더링하는 경우
- 플러그인이나 효과 패키지가 자체 미디어 또는 출력물 이용 조건을 두는 경우
- 라이선스가 적용된 코드, 문서 또는 기타 표현물을 화면이나 음성으로 결과물에 복제하는 경우

따라서 출력물 정책은 소프트웨어 의존성 목록만으로 결정하지 않고 결과물에 들어가는 자산까지 함께 검토합니다.

## 기본 제공 자산 정책

향후 기본 음악, 효과음, 글꼴, 스티커, LUT, 전환 또는 프로젝트 템플릿을 추가할 때는 다음 기준을 적용합니다.

1. 렌더링된 결과물의 개인적·상업적 사용과 배포를 명시적으로 허용해야 합니다.
2. 결과 영상마다 별도 저작자 표시를 요구하거나 동일조건변경허락을 강제하는 자산은 기본 제공 후보에서 제외하는 것을 원칙으로 합니다.
3. 수정, 재배포, 방송 또는 수익화 제한이 있는지 자산별로 확인합니다.
4. 자산의 원본 출처, 저작권자, 버전, 라이선스 문서와 변경 내역을 기록합니다.
5. 승인된 자산은 배포 전에 `THIRD_PARTY_NOTICES` 또는 이에 준하는 고지 파일에 등록합니다.
6. 원본 Windows Movie Maker의 코드, 아이콘, 음원, 영상, 템플릿 및 상표 자산은 복사하거나 재배포하지 않습니다.

## FFmpeg와 코덱

FFmpeg는 기본적으로 LGPL 2.1 이상으로 제공되지만 선택적 GPL 구성 요소를 활성화한 빌드에는 FFmpeg 전체에 GPL 조건이 적용될 수 있습니다. 이는 FFmpeg 바이너리를 묶거나 라이브러리로 연결해 배포할 때 중요한 조건이며, 외부 FFmpeg로 인코딩한 영상 파일 자체에 GPL/LGPL을 부과한다는 뜻은 아닙니다.

H.264/AVC, AAC 및 그 밖의 미디어 규격에는 저작권 라이선스와 별도로 특허 조건이 존재할 수 있습니다. 오픈소스 구현을 사용하거나 애플리케이션을 Apache-2.0, MIT 등의 라이선스로 공개해도 이 문제는 자동으로 해결되지 않습니다. 정식 배포 전에는 다음 항목을 다시 확인합니다.

- 지원 국가와 배포 대상 시장
- FFmpeg 빌드 옵션과 포함된 외부 라이브러리
- 인코더를 애플리케이션과 함께 배포하는지 여부
- 유료 제품, 대량 배포, 스트리밍, 방송 또는 기타 상업적 서비스 여부
- 운영체제가 제공하는 코덱 또는 하드웨어 인코더의 별도 이용 조건

## 배포 전 확인 항목

- 프로젝트 자체 라이선스를 선택하고 `LICENSE`와 `pyproject.toml`에 동일하게 선언합니다.
- 실제 배포 방식에 맞춰 PySide6/Qt와 모든 Python 의존성의 고지·재배포 의무를 확인합니다.
- FFmpeg를 계속 사용자 설치 항목으로 둘지, 특정 빌드를 함께 배포할지 별도 ADR로 결정합니다.
- 번들되는 실행 파일과 미디어 자산을 포함한 서드파티 목록 및 고지 파일을 생성합니다.
- 출력물 권리 안내를 README, 애플리케이션 도움말 및 배포 약관에서 일관되게 유지합니다.
- 상업 배포 전에는 대상 지역을 기준으로 코덱 특허와 상표·자산 사용을 전문적으로 검토합니다.
