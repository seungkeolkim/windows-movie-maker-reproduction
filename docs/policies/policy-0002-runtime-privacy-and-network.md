# 실행 환경 개인정보와 네트워크 정책

- 문서 번호: `POLICY-0002`
- 상태: 승인됨
- 적용 대상: Windows 런처, 환경 구성, 설치·업데이트·제거와 진단 로그

## 기본 원칙

준비된 편집기를 실행하는 동작은 네트워크를 사용하거나 설치 상태를 바꾸지 않는다. 런처는
계정, 로그인, 클라우드 공유와 원격 분석을 제공하지 않으며 진단 로그를 자동 전송하지 않는다.
`--online`은 향후 앱 기능을 명시적으로 허용하는 모드일 뿐 uv 동기화나 제품 업데이트를
허용하지 않는다.

## 네트워크가 가능한 행동

사용자가 설명을 읽고 환경 구성 또는 복구를 승인한 경우에만 패키지에 포함된 uv가 고정
CPython과 `uv.lock`의 패키지를 내려받을 수 있다. 런처는 uv와 FFmpeg를 임의 출처에서 직접
다운로드하지 않는다. uv 실행 파일은 릴리스 빌드에서 공식 배포본의 버전과 SHA-256을 검증해
패키지에 넣는다.
제품 업데이트도 사용자가 새 릴리스 패키지를 받은 뒤 `MovieMakerSetup.exe`에서 시작해야 하며
백그라운드 확인이나 자동 교체는 하지 않는다.

## 로컬 진단 정보

런처는 다음 정보만 로컬 로그에 기록한다.

- 로컬 시간과 점검·구성·실행 단계
- 확인한 uv, FFmpeg와 ffprobe 실행 파일 경로 및 버전
- 자식 프로세스 종료 코드, 취소·시간 초과 여부
- 최대 8 KiB로 제한한 stdout과 stderr

전체 환경 변수, 프로젝트 argv, 미디어 내용, 비밀번호와 토큰은 기록하지 않는다. 사용자 프로필
경로와 일반적인 secret 형식은 저장 전에 redaction한다. 로그는 자동 업로드하지 않으며 기본
14일/10 MiB 경계에서 안전하게 정리한다. 로그 쓰기 실패는 앱 실행을 막지 않는다.

## 제거와 사용자 데이터

기본 제거는 설치 관리자가 소유권을 기록한 제품 파일과 등록만 되돌린다. 프로젝트, 원본 미디어,
최근 프로젝트, 사용자 설정, 캐시, 로그와 자동 저장은 삭제하지 않는다. 캐시·로그·자동 저장은
각각 영향 설명이 있는 별도 제거 선택으로만 삭제할 수 있다.
