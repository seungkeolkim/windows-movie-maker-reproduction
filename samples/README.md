# 로컬 테스트 영상

타임라인·미리 보기·드래그 앤 드롭을 수동으로 확인할 때 다음 파일을 계속 사용합니다.

- 경로: `media/file_example_MP4_1280_10MG.mp4`
- 가져온 위치: 사용자 데스크톱의 동명 파일, 2026-09-18에 복사
- 영상: H.264, 1280×720, 30fps, 약 30.53초, AAC 오디오
- 크기: 9,840,497바이트
- SHA-256: `8ab080c1406dff77f8897955cf977e9ad779e40ab3a07bc2f8694fbd2fc2be21`

앱에서 **미디어 가져오기**로 이 파일을 선택하고 보관함에서 영상·사진 트랙으로 끌어
놓습니다. 긴 클립에는 서로 다른 시간의 프레임이 연속으로 보여야 합니다. 클립을 분할하거나
트림한 뒤에도 각 구간의 장면을 표시해야 하며, 아래의 작은 제목은 폭에 맞춰 말줄임됩니다.
클립 위에서 약 2초 기다리면 전체 제목이 나타납니다.

원본은 그대로 보존했습니다. 로컬 테스트용 파일은 `samples/media/`에 유지하고 Git에서는
제외합니다. 자동 테스트는 별도로 작은 영상을 생성하므로 이 로컬 파일 없이도 실행됩니다.
