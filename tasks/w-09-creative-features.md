# W-09 내레이션·텍스트·전환·시각 효과

## 작업 목표

1.0 창작 흐름의 목업 값인 내레이션, 오디오 페이드·더킹, 제목·캡션·크레딧, 화면 맞춤·채움·
회전, 전환과 제한된 시각 효과를 실제 프로젝트 명령과 미리 보기/출력 합성 그래프에 연결한다.
모든 편집 의도는 저장·열기와 undo/redo에서 보존되고 W-05~W-07이 동일한 의미로 재생·출력해야
한다.

## 선행 상태와 필수 계약

W-01~W-08이 완료된 상태를 전제로 한다. 구현 전에 다음 문서를 확인한다.

- [기능 인벤토리의 `F-AUDIO-06`~`11`](../docs/product/product-0002-feature-inventory.md#f-audio-오디오-편집)
- [기능 인벤토리의 `F-TEXT-01`~`06`](../docs/product/product-0002-feature-inventory.md#f-text-제목과-자막)
- [기능 인벤토리의 `F-VISUAL-01`~`08`](../docs/product/product-0002-feature-inventory.md#f-visual-화면-배치-전환과-효과)
- [요소와 생성 상호작용](../docs/design/design-0002-element-functions.md#e-create-음악-내레이션-텍스트와-전환-생성)
- [내레이션·텍스트·시각 검증 시나리오](../docs/mock/mock-0002-validation-scenarios.md#v-10-02-내레이션과-오디오-속성)
- W-06 오디오, W-07 출력과 W-08 타임라인 설계 계약

실제 파형·프록시 파일 생성과 백그라운드 작업 관리는 W-10 범위다. W-09는 더 이상 장식 파형을
실제 결과처럼 표시하지 않으며, 파형이 없더라도 편집 기능이 동작해야 한다.

## 프로젝트 모델과 명령 공통 요구사항

- 내레이션·텍스트·전환·시각 효과는 UI 목업 상태가 아니라 타입이 있는 불변 프로젝트 값으로
  표현한다.
- 프로젝트 파일에는 사용자 의도와 안정적인 프리셋 ID만 저장한다. FFmpeg 필터 문자열, 장치
  ID, 임시 파일, 렌더 캐시와 위젯 상태를 저장하지 않는다.
- 새 필드는 기존 프로젝트를 안전한 기본값으로 읽는다. 의미가 호환되지 않으면 버전 증가와
  순차 마이그레이션을 구현하고 더 새 버전은 원본을 바꾸지 않은 채 거부한다.
- 모든 지속 편집은 `ProjectCommand`를 통과하고 하나의 적용 행동당 하나의 이력 항목을 만든다.
- 명령 실패는 프로젝트와 행동 이력에 부분 상태를 남기지 않는다.
- 프리셋 ID, 범위와 기본값은 공개 계약으로 문서화하고 알 수 없는 필수 값은 조용히 다른
  효과로 바꾸지 않는다.

## 내레이션과 오디오 요구사항

- 외부 오디오 파일을 고정 내레이션 트랙에 추가하고 시작, source 구간, 음량과 음소거를 편집한다.
- 입력 장치를 선택하고 입력 수준, 시작 위치, 녹음 시간, 시작·일시 정지·계속·완료·취소 상태를
  제공한다.
- 녹음은 UI 스레드를 막지 않는다. 장치 없음, 권한 거부, 장치 분리, 기록 실패와 디스크 부족을
  구분한다.
- 녹음 중에는 고유 임시 파일을 사용한다. 취소·실패·창 종료 시 제거하고, 완료 시에는 사용자가
  확인한 최종 WAV 경로에 원자적으로 확정한 뒤 미디어 보관함과 내레이션 트랙에 추가한다.
- 프로젝트에서 내레이션 클립이나 참조를 제거해도 확정된 원본 WAV를 삭제하지 않는다.
- 음악과 내레이션에 페이드 인·아웃을 적용하며 각 값과 합이 클립 사용 길이를 넘지 않는다.
- 원본음·음악·내레이션의 상대 음량을 한곳에서 조절하되 개별 클립 값과 전체 믹서 값의 곱셈
  순서를 결정적으로 정의한다.
- 내레이션 구간에서 음악을 약하게·보통·강하게 낮추고 문서화된 attack/release로 복귀한다.
- 영상 속도 변경에 따른 원본음 처리 범위와 품질 제한을 명확히 표시한다.
- W-06 공통 오디오 그래프를 확장해 미리 듣기와 W-07 출력에 같은 페이드·더킹·음량 의미를
  제공한다.

## 텍스트 요구사항

- 제목은 프로젝트 시작 또는 현재 장면 앞, 캡션은 현재 재생 위치, 크레딧은 프로젝트 끝을
  기본 시작점으로 한다.
- 텍스트 클립은 종류, 내용, 절대 시작, 표시 시간, 글꼴 계열, 크기, 굵기, 색상, 정렬, 화면
  위치와 제한된 애니메이션 프리셋을 저장한다.
- 빈 내용은 허용하되 편집 화면에는 `텍스트를 입력하세요` 플레이스홀더를 표시한다. 출력에는
  플레이스홀더를 넣지 않는다.
- 기본 스타일은 밝고 어두운 영상 모두에서 읽을 수 있는 대비 수단을 제공하고 안전 영역 안에
  위치한다.
- 글꼴이 없을 때 사용할 대체 규칙을 정의하고 결과가 달라졌음을 진단할 수 있게 한다. 배포할
  글꼴이나 자산은 상업적 출력 허용 조건을 확인한다.
- 긴 크레딧은 편집 가능하고 제한된 스크롤 또는 페이드 애니메이션으로 미리 볼 수 있다.
- 화면 비율과 해상도가 바뀌어도 정규화된 위치와 안전 영역의 의미가 유지된다.

## 화면 배치·전환·효과 요구사항

- 시각 클립별로 `맞춤`과 `채움`을 선택한다. 맞춤은 전체 내용을 보이고 중립 여백을 사용하며,
  채움은 비율을 유지한 채 중앙 기준으로 넘치는 영역을 자른다.
- 사용자 회전은 입력 파일 회전 메타데이터를 적용한 결과에 추가되는 `0/90/180/270도` 편집값이다.
- 밝기와 소수의 기본 색상·시각 효과를 안정적인 프리셋과 제한된 매개변수로 제공한다.
- 전환은 인접한 두 시각 클립 ID의 경계에만 존재한다. 기본 페이드와 제한된 대표 프리셋을
  제공한다.
- 전환 길이는 양쪽 클립의 사용 가능한 source 구간과 프로젝트 길이를 침범하지 않는다.
- 이동·삭제·다중 편집 뒤 인접 관계가 사라진 전환은 같은 명령에서 제거되며 undo로 복원된다.
- 전환이 클립 겹침을 사용한다면 프로젝트 시간, 오디오 처리와 전체 길이에 미치는 규칙을
  명시하고 미리 보기와 출력에 동일하게 적용한다.
- 사용자 프로젝트에 임의 필터 문자열이나 실행 가능한 효과 코드를 저장하거나 실행하지 않는다.

## 미리 보기·출력 동등성

- 미리 보기는 현재 위치의 텍스트, 맞춤·채움·회전·효과와 전환을 실제 합성 결과로 표시한다.
- W-07 출력은 동일한 프로젝트 값과 공통 계획기를 사용한다. UI용 근사값과 별도 의미를 만들지
  않는다.
- 캔버스 크기에 따른 미리 보기 축소는 최종 좌표·안전 영역 계산 이후의 표시 변환이어야 한다.
- 연속 탐색과 편집 직후 오래된 합성 결과를 폐기한다.
- 누락 미디어나 사용할 수 없는 프리셋은 마지막 정상 프레임을 새 결과처럼 남기지 않고 오류와
  해결 행동을 표시한다.

## 필수 자동 검증

- 외부 내레이션 추가, 녹음 상태 전이, 임시 파일 정리와 최종 WAV 원자적 확정
- 장치 없음·권한 거부·분리·기록 실패에서 프로젝트와 정상 파일 불변
- 음량 믹서, 페이드 경계, 더킹 attack/release와 미리 보기/출력 공통 결과
- 제목·캡션·크레딧 기본 위치와 모든 스타일의 저장·열기·undo/redo
- 빈 텍스트의 UI 플레이스홀더와 출력 제외
- 안전 영역, 화면 비율, 글꼴 대체와 제한된 애니메이션
- 맞춤·채움의 기하, 회전 메타데이터와 사용자 회전의 결합
- 효과 프리셋의 범위와 알 수 없는 ID 거부
- 전환 인접성, 길이 제한, 이동·삭제 뒤 정리와 undo 복원
- 대표 프레임과 오디오 샘플을 사용한 미리 보기/MP4 출력 동등성
- 기존 프로젝트 호환, 스키마 왕복, 모든 명령의 실패 원자성
- W-01~W-08 및 전체 Qt UI 회귀

렌더 결과는 단순히 명령 문자열만 비교하지 않고 작은 실제 미디어의 픽셀·프레임 시간·오디오
구간을 허용 오차 안에서 검증한다. 녹음 테스트는 주입 가능한 가짜 입력 장치를 사용한다.

## UI와 접근성 요구사항

- 속성 패널은 선택 종류에 맞는 오디오, 텍스트 또는 시각 페이지를 표시한다.
- 비활성 컨트롤은 필요한 선택·장치·인접 클립 등 이유를 제공한다.
- 색상만으로 효과, 선택, 녹음과 오류 상태를 전달하지 않는다.
- 모든 필드는 키보드로 접근 가능하고 포커스 순서가 화면 순서와 일치한다.
- 녹음 중 상태와 경과 시간은 보이는 텍스트로 제공하고 보조 기술이 상태 변화를 인식할 수 있다.

## 문서와 완료 조건

- 프로젝트 스키마, 명령, 오디오 확장, 텍스트 레이아웃, 전환과 합성 계약을 하나 이상의 새
  `DESIGN` 문서로 기록한다.
- 장기 아키텍처나 기존 스키마 의미를 바꾸면 새 ADR에 근거와 호환 영향을 기록한다.
- README, 문서 지도, 기능·요소 표와 목업 연결 상태를 실제 구현에 맞게 갱신한다.
- `V-10-02`, `V-10-03`, `V-10-04`의 목업 단계를 실제 서비스 검증으로 교체한다.
- 집중 테스트와 전체 pytest, Ruff, strict mypy, 애플리케이션 점검이 모두 통과한다.
- 대표 프로젝트의 미리 보기와 1080p MP4를 비교해 텍스트 위치, 전환, 효과와 음량이 일치한다.

## 범위 제외

- 전문 색보정, 모션 그래픽 편집기, 노이즈 감소와 EQ
- 사용자 정의 효과 플러그인과 무제한 합성
- 영상 안정화, 크로마키와 속도 램핑
- 실제 파형·프록시 생성과 캐시 수명주기
- 클라우드 음성 처리 또는 온라인 자산
