# W-08 고급 타임라인과 행동 이력 UI

## 작업 목표

W-04의 실제 단일 클립 명령과 세션 행동 이력 위에 클립 복제, 호환되는 다중 선택, 그룹 이동·
삭제, 안정적인 리플 편집, 스토리보드 보기와 타임라인 확대를 구현한다. 목업 상태 복사에 남아
있는 고급 타임라인 행동을 모두 실제 불변 프로젝트 명령 또는 명시적인 세션 보기 상태로
교체한다.

## 사용자 결과

- 선택한 클립을 같은 편집 설정으로 바로 뒤에 복제할 수 있다.
- `Ctrl`/`Shift` 입력으로 호환되는 여러 클립을 선택하고 한 번에 이동하거나 삭제할 수 있다.
- 실행 취소·다시 실행 메뉴는 다음에 적용될 행동 이름을 표시한다.
- 여러 클립에 대한 한 번의 사용자 행동은 한 번의 실행 취소로 되돌아간다.
- 타임라인과 스토리보드 보기를 전환해도 같은 프로젝트, 선택과 재생 위치가 유지된다.
- 확대·축소로 눈금과 클립 폭을 바꿀 수 있으며 실제 편집점은 변하지 않는다.
- 끌기 이동은 삽입 위치와 허용 여부를 미리 표시하고 키보드 명령과 같은 결과를 만든다.

## 선택과 명령 요구사항

- 선택은 세션 UI 상태이며 프로젝트 JSON, dirty 기준과 행동 이력에 들어가지 않는다.
- 단일 선택은 기존 속성 패널과 미리 보기 위치 연결을 유지한다.
- 다중 선택은 같은 트랙에서 함께 처리할 수 있는 클립만 허용한다. 서로 다른 트랙이나 호환되지
  않는 조합은 암묵적으로 일부만 처리하지 말고 이유를 표시한다.
- `Ctrl` 선택은 개별 토글, `Shift` 선택은 같은 트랙의 연속 범위로 동작한다.
- 선택 집합이 프로젝트 편집으로 사라지거나 ID가 바뀌면 남은 유효 ID만 유지하고 대표 선택을
  결정적으로 고른다.
- 다중 선택 속성 패널은 선택 수와 공통 행동만 표시하며 서로 다른 값을 하나의 값인 것처럼
  보여 주지 않는다.

## 복제·그룹 이동·삭제 요구사항

- 복제본은 새 고유 clip ID를 사용하고 같은 원본 미디어 참조와 지속 편집 속성을 보존한다.
- 단일 복제는 원본 바로 뒤에 놓는다. 시각 트랙은 이후 클립을 리플하고 절대 시간 트랙은
  명시된 삽입 위치 충돌 정책을 따른다.
- 시각 트랙의 그룹 이동은 선택 클립의 내부 순서를 유지한 채 하나의 삽입 지점으로 재배치하고
  전체 시각 트랙을 0부터 빈틈없이 다시 계산한다.
- 음악·내레이션·텍스트 같은 절대 시간 트랙의 그룹 이동은 공통 시간 델타를 적용해 선택 간
  상대 간격을 유지하며 0 이전으로 이동하지 않는다.
- 그룹 삭제는 모든 대상을 검증한 후 한 번에 적용한다. 하나라도 유효하지 않으면 전체 명령을
  거부하고 부분 삭제를 남기지 않는다.
- 시각 삭제·삽입·이동 뒤 보조 트랙의 절대 시작 시간은 암묵적으로 리플하지 않는다.
- 이후 W-09 전환처럼 인접 관계에 종속된 상태를 정리할 수 있는 명시적인 명령 경계를 둔다.
- 명령은 전체 프로젝트 스냅샷 대신 되돌리기에 필요한 최소 값과 순서를 보관한다.

## 행동 이력 요구사항

- 복제, 그룹 이동과 그룹 삭제는 실제 `ProjectCommand`를 통과한다.
- 적용 전 전체 입력과 결과 불변식을 검증하며 실패 시 프로젝트와 이력 위치가 변하지 않는다.
- undo 후 redo는 최초 적용과 같은 프로젝트 값을 만들고 동일한 선택 복원 정책을 사용한다.
- undo 뒤 새 편집을 수행하면 기존 redo 후보를 제거한다.
- 저장은 현재 결과만 기록하고 이력은 유지한다. 새 프로젝트와 열기는 빈 이력으로 시작한다.
- 선택, 스토리보드 전환, 확대, 스크롤과 재생 위치는 행동 이력에 기록하지 않는다.
- 기존 W-04 단일 클립 행동과 새 그룹 행동이 같은 실행기를 사용한다.

## 보기와 입력 요구사항

- 타임라인 보기는 시간 눈금, 네 고정 트랙, 재생 헤드와 실제 절대 위치를 표시한다.
- 스토리보드는 시각 클립을 같은 순서의 큰 카드로 표시하고 음악·내레이션·텍스트는 요약한다.
- 두 보기는 별도 프로젝트 복사본을 만들지 않고 동일한 `Project`와 선택 모델을 관찰한다.
- 확대 수준은 문서화된 최소·최대 범위에서 단계적으로 바뀌며 클립 폭과 시간 눈금만 바꾼다.
- `Ctrl+휠`과 화면 컨트롤이 같은 확대 경계를 사용하고, 가능한 경우 포인터나 재생 헤드 주변
  시간 위치가 화면에서 유지된다.
- 끌기 중 실제 프로젝트를 계속 변경하지 않는다. 유효한 놓기에서 명령 하나를 실행하고 취소,
  원위치 놓기와 잘못된 위치는 이력에 남기지 않는다.
- `Ctrl+D`, `Delete`, `Ctrl+Z`, `Ctrl+Y`와 메뉴/버튼은 포커스 문맥을 존중한다. 텍스트 입력과
  운영체제 기본 단축키를 가로채지 않는다.
- 키보드만으로 선택, 복제, 이동, 삭제, 실행 취소·다시 실행과 보기 전환에 접근할 수 있다.

## 오류와 경계 상태

- 빈 선택, 사라진 clip ID, 혼합 트랙, 호환되지 않는 그룹, 범위 밖 이동과 ID 충돌을 구분한다.
- 한계 위치에서 이동할 수 없는 이유를 표시하고 조용히 성공으로 기록하지 않는다.
- 누락 미디어 클립도 구조 편집은 가능하되 원본이 필요한 속성이나 미리 보기와 구분한다.
- 출력 또는 다른 장시간 작업 중 편집이 금지된 경우 같은 비활성 상태 계약을 사용한다.

## 필수 자동 검증

- 단일·연속·토글 선택과 편집 후 선택 정리
- 복제의 새 ID, 모든 지속 속성 보존과 원본 비수정
- 시각 그룹 이동의 상대 순서·리플·전체 길이
- 절대 시간 트랙 그룹 이동의 공통 델타와 0 경계
- 그룹 삭제의 원자성, undo/redo 왕복과 이력 분기
- 혼합·비호환 선택의 전체 거부와 상태 불변
- 끌기 취소·잘못된 위치·원위치 놓기의 무변경
- 타임라인/스토리보드 전환과 확대가 프로젝트·dirty·이력에 미치는 영향 없음
- 보기 전환 뒤 선택, 재생 위치와 속성 문맥 유지
- 메뉴 행동 이름과 모든 단축키의 포커스 문맥
- 저장·열기 왕복 및 W-01~W-07 전체 회귀

속성 기반 테스트로 임의의 시각 클립 순서와 그룹 이동·삭제 뒤 연속 배치, 고유 ID, 참조와
undo/redo 불변식을 검증한다.

## 문서와 완료 조건

- 선택 모델, 그룹 명령, 리플, 보기 상태와 키보드 계약을 새 `DESIGN` 문서로 기록한다.
- README, 문서 지도, 요소 표와 목업 연결 상태를 실제 결과에 맞게 갱신한다.
- W-08에 해당하는 목업 상태 복사 경로가 실제 명령과 세션 보기 상태로 교체된다.
- 집중 테스트와 전체 pytest, Ruff, strict mypy, 애플리케이션 점검이 모두 통과한다.
- 1280×720과 작은 지원 창 크기에서 타임라인·스토리보드·다중 선택의 시각 상태를 확인한다.

## 범위 제외

- 무제한 영상 레이어와 자유 합성 트랙
- 마커, 슬립 편집과 속도 램핑
- 세션을 넘어 지속되는 행동 이력
- W-09 텍스트·전환·효과 내용 구현
- W-10 자동 저장, 프록시와 백그라운드 작업
