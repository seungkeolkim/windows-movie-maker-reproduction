W-06 원본음·음악 믹싱을 완전히 구현하라.
현재 목업인 오디오 동작을 실제 프로젝트 상태, FFmpeg 기반 처리, 재생 가능한 미리 듣기로 교체하라.
영상 원본음과 배경 음악을 하나의 결정적인 공통 오디오 그래프로 해석하고 W-07 내보내기에서도 재사용할 수 있게 하라.

착수 전에 AGENTS.md와 tasks/w-06-audio-mixing.md 전체 및 그 문서가 지정한 승인 계약과 현재 구현을 읽어라.
기존 W-01부터 W-05까지의 시간, 불변 프로젝트, 명령 이력, 저장 호환성, 미리 보기 동시성 계약을 유지하라.
클립별 음량과 음소거, 음악의 절대 시작 위치와 source in/out, 트리밍, 영상 재생 속도를 타입이 있는 프로젝트 값과 원자적 ProjectCommand로 구현하라.
음소거 해제 시 기존 음량을 보존하고 모든 변경의 undo와 redo 및 저장과 열기 왕복을 보장하라.

서로 다른 샘플률과 채널 구성을 정규화하고 클리핑 정책을 명시하며 오디오 없는 영상은 정상 무음으로 처리하라.
재생, 일시 정지, 탐색, 연속 탐색, 편집, 프로젝트 교체와 종료에서 오래된 작업과 FFmpeg 프로세스 및 오디오 자원을 안전하게 취소하고 정리하라.
UI 스레드를 막지 말고 실제 장치 없이도 검증할 수 있도록 시계, 프로세스 실행기와 오디오 출력을 주입 가능하게 설계하라.
사용자 입력과 경로를 셸 문자열로 실행하지 말고 구조화된 인자와 안전한 필터 구성을 사용하라.

기존 속성 패널과 재생 컨트롤을 실제 명령과 오디오 상태에 연결하고 관련 목업 표시만 제거하라.
집중 단위 테스트, 실제 FFmpeg 통합 테스트, Qt 통합 테스트와 전체 회귀 테스트를 추가하라.
pytest, Ruff, strict mypy와 git diff --check를 모두 통과시키고 새 DESIGN 문서, 문서 지도와 README 진행 상태를 실제 결과에 맞게 갱신하라.
마이크 녹음, 내레이션, 파형, 프록시, 페이드, 자동 더킹, 시각 효과와 실제 MP4 생성은 이번 범위에 포함하지 마라.
