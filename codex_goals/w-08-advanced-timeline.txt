W-08 고급 타임라인과 행동 이력 UI를 완전히 구현하라.
W-04의 실제 단일 클립 명령과 행동 이력 위에 복제, 다중 선택, 그룹 편집, 스토리보드 보기와 타임라인 확대를 연결하라.
남아 있는 고급 타임라인 목업 상태 복사 경로를 실제 불변 프로젝트 명령 또는 명시적인 세션 보기 상태로 교체하라.

착수 전에 AGENTS.md와 tasks/w-08-advanced-timeline.md 전체 및 연결된 승인 계약과 현재 구현을 읽어라.
작업 트리가 깨끗하고 main이 origin/main과 동기화됐는지 확인한 뒤 main에서 feat/w08-advanced-timeline 브랜치를 새로 생성하라.
같은 이름의 브랜치가 이미 있거나 안전하게 생성할 수 없으면 기존 상태를 덮어쓰지 말고 원인을 확인하라.
모든 W-08 구현, 테스트와 문서 변경은 새 기능 브랜치에서만 수행하고 main에 직접 커밋하지 마라.

W-01부터 W-07까지의 정수 나노초 시간, 불변 Project, 명령 원자성, JSON 호환성, 미리 보기, 오디오와 MP4 출력 계약을 유지하라.
선택, 스토리보드 전환, 확대, 스크롤과 재생 위치는 프로젝트 JSON이나 dirty 기준 및 행동 이력에 기록하지 마라.
지속되는 복제, 그룹 이동과 그룹 삭제는 실제 ProjectCommand를 통과시키고 한 번의 사용자 행동을 한 번의 undo로 되돌릴 수 있게 하라.
명령은 전체 프로젝트 스냅샷 대신 되돌리기에 필요한 최소 값만 보관하고 모든 입력 검증이 끝난 뒤 원자적으로 적용하라.

Ctrl 선택은 같은 트랙 항목의 개별 토글, Shift 선택은 연속 범위로 구현하라.
혼합 트랙이나 호환되지 않는 선택은 일부만 처리하지 말고 전체를 거부하며 이유를 표시하라.
편집으로 선택 항목이 사라지면 유효한 clip ID만 남기고 대표 선택을 결정적으로 선택하라.
다중 선택 속성 화면은 선택 수와 공통 행동만 표시하고 서로 다른 값을 하나의 값처럼 보여 주지 마라.

복제본은 새 고유 clip ID와 기존 원본 참조 및 지속 편집 속성을 보존하며 원본 바로 뒤에 배치하라.
시각 그룹 이동은 내부 순서를 유지하고 전체 시각 트랙을 0부터 빈틈없이 다시 계산하라.
음악, 내레이션과 텍스트 그룹 이동은 공통 시간 델타와 상대 간격을 유지하고 0 이전 이동을 거부하라.
그룹 삭제는 전체 대상을 먼저 검증하고 실패 시 프로젝트와 이력 위치를 전혀 바꾸지 마라.
시각 트랙 편집이 절대 시간 보조 트랙을 암묵적으로 리플하지 않도록 하라.

타임라인과 스토리보드는 같은 Project와 선택 모델을 관찰하고 보기 전환 뒤에도 선택과 재생 위치를 유지하라.
확대와 축소는 눈금과 클립 표시 폭만 바꾸며 실제 편집점, 프로젝트, dirty와 이력을 변경하지 마라.
끌기 중에는 프로젝트를 반복 변경하지 말고 유효한 놓기에서만 명령 하나를 실행하라.
끌기 취소, 잘못된 위치와 원위치 놓기는 프로젝트와 이력에 아무 변화도 남기지 마라.
Ctrl+D, Delete, Ctrl+Z와 Ctrl+Y는 텍스트 입력을 방해하지 않도록 포커스 문맥을 존중하라.
키보드만으로 선택, 복제, 이동, 삭제, undo와 redo 및 보기 전환에 접근할 수 있게 하라.

빈 선택, 사라진 clip ID, 혼합 트랙, 호환되지 않는 그룹, 범위 밖 이동과 ID 충돌을 타입이 있는 오류로 구분하라.
출력 중 편집 허용 정책은 W-07의 불변 시작 스냅샷 계약과 일치시켜라.
원본 미디어와 정상 프로젝트 파일을 수정하거나 삭제하지 마라.

집중 명령 테스트, 선택 모델과 Qt 통합 테스트, 속성 기반 그룹 편집 테스트 및 W-01부터 W-07까지의 전체 회귀 테스트를 추가하라.
pytest, Ruff, strict mypy, 애플리케이션 점검과 git diff --check를 모두 통과시켜라.
선택 모델, 그룹 명령, 리플, 보기 상태와 키보드 계약을 새 DESIGN 문서에 기록하라.
README, 문서 지도, 요소 표, 목업 연결 상태와 tasks의 완료 상태를 실제 결과에 맞게 갱신하라.
1280×720과 최소 지원 창 크기에서 타임라인, 스토리보드와 다중 선택 상태를 확인하라.

무제한 영상 레이어, 마커, 슬립 편집, 속도 램핑, 세션을 넘어 지속되는 행동 이력, W-09 효과와 W-10 자동 저장·프록시는 이번 범위에 포함하지 마라.
